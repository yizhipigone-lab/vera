## 〇、结论先行（可信度总评）

**回测机制层可信（PASS 占绝大多数），但结果整体仍不可按绝对值采信，且发现 1 个 HIGH 级数据层问题与若干 MEDIUM/LOW 问题。**

- ✅ **通过**: 回撤计算、逐笔止盈止损机制（12 笔全部手工重算吻合）、T+1/涨停过滤/停牌/时间止损等边界、权益曲线构建（2014-01 逐 bar 重放期末吻合到 0.72 元）、pct2-vs-pct10 口径 100% 一致
- ⚠️ **HIGH**: 5m 与 1d 数据缓存的**前复权口径系统性不一致**（抽样 64% 的股-日偏离>1%，中位比值 0.856~1.434，且比值随时间漂移）；5m 缓存内部存在**复权断裂假跳变**（如 002410 +368%、300324 -92% 单日假跳，1d 同日正常）
- ⚠️ **MEDIUM**: 引擎版本号与执行口径命名矛盾（已查明为纯版本标签，非 bug）；Sharpe 计算口径标注错误（bar 级收益按日年化）；trades.csv 的 entry_amount/exit_amount 为毛额、pnl 为净额（口径混用）
- ⚠️ **LOW**: 29 笔"退市"全部实为停牌/数据截止被误标（无一真退市）；降级日填充混入异尺度价格（44 笔受影响，量级 <0.5%）；任务提示中"最大回撤 -5.62%（2018-09~10）"与事实不符（真实最大回撤 -5.94% 在 2015-08，2018 段为 -5.86%）
- **未发现**: 前视偏差、T+1 违规（0 笔同日买卖）、方向性回撤 bug、权益曲线构造错误

## 一、各维度发现

### A. 回撤计算逻辑 — ✅ 通过

三处回撤计算均为标准 cummax 语义，无方向/基数/峰值 bug：

| 位置 | 公式 | 判定 |
|---|---|---|
| [backtest/engine.py:880-881] | `peak=expanding().max(); dd=(equity-peak)/peak` | 正确 |
| [backtest/metrics.py:177-183] | `peak=expanding().max(); dd=(equity-peak)/peak; min()` | 正确 |
| [research/run_quantqq_2014_5m_yearly_pct.py:520-521] | 聚合后 `cummax; equity/peak-1` | 正确 |
| [research/run_quantqq_2014_5m_yearly_pct.py:540-542] | `np.maximum.accumulate; eq/peak-1` | 正确 |

**数值复算**（对 equity_curve.csv 全 147,216 行）:
- 重算 mdd = CSV drawdown 列 = metrics.json = **-0.05943907**（三者一致，偏差 6.9e-17）
- 谷底 **2015-08-06 09:35**，峰值 2015-07-27 10:30（6,375,345 元），修复于 2015-08-10 09:50
- **任务提示的"最大回撤 -5.62%（2018-09~10）"与实际不符**: 全局最大回撤是 2015-08 的 **-5.94%**；2018-09-26~10-12 段为 **-5.86%**（第二深）。-5.62% 无任何来源吻合。

### B. 止盈止损逐笔机制（核心）— ✅ 通过（12 笔全部吻合）

抽样 12 笔覆盖全部 7 种退出原因，逐笔用 `data/kline_cache/5m/<code>.parquet` 重放。机制实现:

- **买入**: [backtest/loop/entry.py:91-92] `bp = price_np[i,ci]`（close_t 下即 T 日 15:00 bar 收盘价），全部抽样 entry_price = 信号日 5m 最后一根 bar close ✓
- **移动止盈 confirm="real"**: [backtest/loop/strategies/trailing.py:121-144] 三态: 本 bar 创峰值跳过 / 开盘<线按开盘价 / Low 触线按线价; 线 = peak_hi×(1-0.005)；激活 = peak_hi_profit≥3% [backtest/loop/strategies/trailing.py:76-77]
- **成本止损**: [backtest/loop/strategies/cost_stop.py:31-41] 线 = ep×(1-0.06)，跳空低开按 open [backtest/loop/strategies/cost_stop.py:36-38]
- **时间止损**: [backtest/loop/strategies/time_stop.py:26-31] hold_days≥max_hold_days 按 bar close 成交；**max_hold_days 缩放**: [backtest/engine.py:400] `mhd_scaled = 12 × bpday(48) = 576` bars（抽样 3 笔全部 bars_held=576，hold_days=12 ✓）
- **换股卖出**: [backtest/loop/entry.py:99-109] 持仓中同票再出信号 → 以新信号日收盘卖旧仓（reason=1，仅扣佣金无滑点无印花税），抽样 000526/000725 卖出价=退出日 15:00 close ✓
- **移动止损（亏损版）**: 与移动止盈同一 `_check_real`，`reason=8 if (exec-ep)/ep>0 else 4` [backtest/loop/strategies/trailing.py:140-141]，抽样的 2015-07-01 股灾两笔均为跳空按开盘价成交 ✓

**逐笔对照表**（详见文末附表）: 12/12 笔 entry_price、exit_price、exit_reason、hold_days 与 CSV 完全一致（重放触发价与 CSV 偏差 <1e-3）。其中 300051.SZ 首轮重放因漏 activation 条件判"不一致"，修正后确认触发机制正确: 13:40 创新高 9.3289 → 13:45 开盘 9.2793 < 线 9.2823 → 按开盘价 9.2793 成交 = CSV ✓。**未发现任何逐笔机制错误。**

### C. 边界条件 — ✅ 通过

- **T+1**: [backtest/loop/loop.py:288-297] 同日 `(i//bpday)==(entry_idx//bpday)` 跳过卖出检查；trades.csv 0 笔同日买卖（min hold_days=1）✓
- **涨停过滤**: [backtest/engine.py:1149-1182] 5m 下相对前一**交易日**收盘判定 [backtest/engine.py:1163-1169]；`cv >= prev×(1+ratio)×0.997` [backtest/engine.py:1175] 0.3% 容差 ✓

- **费用**: 买入 `bp×1.001×1.0003` [backtest/loop/entry.py:148-149]；卖出 `xp×0.999×0.9992` [backtest/loop/loop.py:413-414]；换股 `xp×(1-0.0003)` [backtest/loop/entry.py:104]。与 config/strategy_QUANTQQ.yaml 的 commission=0.0003/slippage=0.001 及 engine 默认 stamp_tax=0.0005、realistic_costs=True [backtest/engine.py:124-131] 一致

### E. 数据层 — ❌ HIGH（复权口径系统性不一致 + 5m 缓存断裂）

**E-1 5m 与 1d 缓存前复权口径系统性不一致（HIGH）**

抽样 60 只股票、163,382 个股-日对对比"5m 日聚合收盘 vs 1d 收盘":
- **64.19% 的股-日对偏离 >1%**（绝非噪声）
- 各股中位比值 0.856~1.434（如 600383 5m 比 1d 高 27.5%、002410 高 43%、000065 低 14%）
- 比值**随时间漂移**（000600: 2005=3.47 → 2014=1.54 → 2026=1.00；002410: 2012=6.68 → 2020=1.43 → 2026=1.00），即 5m 与 1d 的前复权**除权事件链不一致**（缺失或错配部分分红/送转因子）
- 引擎自身已发现并告警: [backtest/degrade_5m.py:169-193] 复权一致性检查，2021 段日志报 **"open 字段 844,838 处 5m 日聚合 != 1d（首处 2021-01-04 000002.SZ: 5m=28.40 1d=25.49）"**（复现于 `_cap1e8_run.log`）；全期 adjust_mismatches 累计 33,663,083 处

**E-2 5m 缓存内部存在复权断裂假跳变（HIGH）**

同一只股票 5m 序列在除权日出现远超涨跌停限制的假跳变（1d 同日完全正常）:
- 002410.SZ: 2012-06-11 +368%、2014-01-02 -69%、2015-01-05 +144%、2023-03-24 -29%（1d 同日 +7%/-3%/+3%/+0.2%）
- 300324.SZ: 2014-01-02 -92%（1d 同日 -2.9%）
- 603030.SH: 2020-01-02 +101%；688301.SH: 2024-02-01 +184%
- 全市场扫描（4,388 只交易股票）: 24 个(股,日)断裂点落在交易窗口内

**对本次回测的实际影响（量级有限）**:
1. 交易多在断裂**当日**15:00 入场（买入断裂后新尺度），出场也在同尺度 → **单笔收益率不受全局尺度因子影响**（尺度在 (exit-entry)/entry 中抵消）
2. 向上断裂日会被涨停过滤 [backtest/engine.py:1175] 误判为涨停 → **错过少量入场**（无法精确计数，个位数级别）
3. 持仓**跨越**断裂日: 全量扫描未发现 5m 与 1d 同时异常的跨越案例（唯一跨越的 000564 2021-12-31 两缓存一致，是真涨跌）
4. 降级填充: 全期 23,422 个股-天用 1d OHLC 填 5m 网格 [backtest/degrade_5m.py:196-209]，**对持仓影响 44/39,563 笔（0.111%）**，2021 段降级影响报告显示受影响 2 笔、影响金额 [-183万, +851万]（相对该段 16 亿资金 <0.6%）

**E-3 前视偏差: 未发现**。信号（1d 选股，TDX 服务端）→ 回测 T 日 15:00 收盘买入，信号日数据完整后才成交；无未来 bar 参与；降级 bar 峰值推迟 [backtest/loop/loop.py:80-88, 283-287] 是保守方向。

### G. 统计异常 — 全部给出解释（无未解异常）

1. **152 个自然月 0 亏损月（最小 2017-01 +0.42%）** — 自洽，非 bug:
   - 月收益 mean=+10.04%、std=4.38%（n=151），mean/std=2.29 → 正态近似下单月亏损概率 1.09%，151 个月全正的概率约 **19%**，统计学上并不反常
   - 结构原因: 81.4% 胜率 + 月均 ~250 笔交易 → 月收益是大量小盈亏之和（CLT 收敛），方差小、漂移大
   - 亏损日占比 24.5% 与月恒正不矛盾（日内回撤在月末前修复，最大回撤 -5.94% 发生在 2015-08 月内）
2. **2014-2019 年化 134%~362% vs docs/audit 16.77%** — 口径不同，不构成矛盾:
   - 本次 pct2 实际逐年: 2014 +134%（首年资金小、现金受限）、2015 +362%、2016 +173%、2017 +183%、2018 +148%、2019 +150%、2020 +212%、2021 +293%、2022 +263%、2023 +196%、2024 +241%、2025 +180%、2026 +176%
   - 16.77% 出自 [docs/audit/2026-07-19_三因子评分相关性_分析报告.md:90]，是 **1d 引擎 + 3 年窗（2023-07~2026-07）+ 3644 信号 + trailing_first(6%/0.3%) 配置**的因子体检，与 5m + stop_first(3%/0.5%) + 2% 动态仓位的本回测完全不可比
   - **注意**: trailing 基准的"2014 +124% → 2026 +6.4% 递减"是固定 2 万/笔仓位在权益复利下资金利用率塌陷的假象（本实验已验证: 2% 动态仓位下无递减）——该假说成立 ✓
3. **entry_date 全 15:00 vs 引擎名 "VeraCore v3.7-entry-t1-open-20260820"** — 命名矛盾已澄清:
   - [backtest/engine.py:39] `ENGINE_VERSION = "v3.7-entry-t1-open-20260820"` 只是**版本号/矩阵缓存键**（在 2026-08-20 open_t1 功能上线时定名），不代表本次运行模式
   - 本次运行明确 close_t: [research/run_quantqq_2014_5m_yearly_pct.py:183] `pipe.config["backtest"]["entry_price_mode"] = "close_t"`；[backtest/engine.py:470-471] close_t → `_filter_limit_up` 分支；日志"涨停过滤: 移除 517 个涨停买入信号"（open_t1 会关闭该过滤）证实实际执行 close_t；trades.csv 全 37,525 笔 entry_date=15:00 且 entry_price=当日 5m 收盘 ✓

## 三、问题清单（按严重度）

### HIGH
- **H-1 5m/1d 缓存前复权口径系统性不一致** [backtest/degrade_5m.py:169-193]。证据: 抽样 64% 股-日偏离>1%、中位比值 0.856~1.434、引擎自身告警 84.4 万处（2021-01-04 万科 5m=28.40 vs 1d=25.49）。影响: 降级填充日混入异尺度价（44 笔、量级小）；与旧缓存运行（trailing 基准）对比失真；5m 自身断裂日涨停过滤误判。**修复方向**: 统一 5m/1d 的除权事件链（同一调整源），或降级时按当日比例因子折算。
- **H-2 5m 缓存内部复权断裂（假跳变）**。证据: 002410 2012-06-11 +368%、300324 2014-01-02 -92%、688301 2024-02-01 +184%（1d 同日正常）。影响: 断裂日入场价错尺度（个别）、向上断裂日被涨停过滤误拒、标记为"退市"的 29 笔交易其实全是停牌/数据截止被强平（无一真退市，全部股票 2026 年仍在交易）。**修复方向**: 5m 缓存重建时校验日聚合=1d；"退市"判定应区分真退市与数据截止/停牌。

### MEDIUM
- **M-1 Sharpe 计算口径标注错误** [research/run_quantqq_2014_5m_yearly_pct.py:544-545]: 用 5m **bar 级**收益序列 ×sqrt(252) 冒充日收益年化。bar 级年化应为 ×sqrt(48×252)，日采样年化 ≈9.0（bar mean/std=0.0871 时引擎口径 ≈9.6）。报告的 Sharpe 1.38 是错标口径，与引擎 _log_results 报的 15.87 同源不同标。需注明口径或改采样。
- **M-2 trades.csv 金额口径混用**: entry_amount/exit_amount 为毛额（价×股数，不含费）[backtest/engine.py:932-933]，而 pnl 为净额（含滑点+佣金+印花税）[backtest/loop/loop.py:413-419]。`exit_amount-entry_amount ≠ pnl`（首笔 976.58 vs 940.44）。文档需注明。
- **M-3 与 trailing 基准的 0.28% 交易数据口径不一致**（旧缓存降级价），两口径对比时需剔除或重跑基准。

### LOW
- **L-1 "退市"标签误用**: 29 笔全部为停牌/数据截止强平 [backtest/loop/loop.py:254-270] 的 ffill 价成交，无一真退市。
- **L-2 任务提示两个数字与事实不符**: 最大回撤实为 -5.94%（2015-08）而非 -5.62%（2018-09~10 实为 -5.86%）；152 个月应为 151 个有收益的月（+2014 首个基准月）。
- **L-3 月中权益重放最大偏差 2.3%**（2014-01-16，4 只持仓股停牌/降级的计价源差异），月末收敛到 0.72 元，不影响结论。
- **L-4 测试套件漂移（审计当日核验，已解决）**: 工作区流动性约束特性（2026-08-28，`loop.run()` 新增 `turnover_day_np` 参数 [backtest/engine.py:451]）曾致 `tests/test_degrade_5m.py` 与 `tests/test_engine_5m_window.py` 的 `_MockLoop.run()` 报 `TypeError`（15 个测试失败）。**审计后已由接管会话同步修复**: 四个文件（test_degrade_5m / test_engine_5m_window / conftest / test_matrix_cache）的 `_MockLoop.run()` 均补 `turnover_day_np=None`，全量 pytest 恢复 **1946 passed, 0 failed**。属 CI 卫生问题，随流动性约束特性一并闭合。

## 五、建议

1. **修数据层（最高优先）**: 统一 5m 与 1d 的前复权除权链（同一调整因子源），重建 5m 缓存并加"日聚合=1d"校验门禁；修复后重跑 pct2/pct10/trailing 三口径并重新对比。
2. **区分"退市"与"停牌/数据截止"**: [backtest/loop/loop.py:252-270] 的 `i > last_tradable_idx` 强平语义保留（不可交易就该卖），但 reason 标签应区分，且退市价应有真实末日价而非一律 ffill。
3. **修正 Sharpe 口径**: bar 级收益 ×sqrt(48×252) 才是 5m 年化；或改为日采样收益 ×sqrt(252)；报告中注明口径。
4. **trades.csv 增加 fee 列**: 让 entry_amount/exit_amount/pnl 口径自洽可复核。
5. **对比基准前先验数据一致性**: trailing 基准与 pct2 存在 0.28% 交易的旧缓存错价，任何跨运行对比前先对齐缓存。
6. **资金规模警示**: 绝对收益按"相对排序 + 单笔占比"读，不按绝对金额读；流动性上限（max_turnover_pct / MAX_BUY）应纳入正式配置。
