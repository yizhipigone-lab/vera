# GUPIAO_018(捉妖) 新体系研究报告（大白话版）

> 2026-08-04 · 流程: tdx-strategy-research 技能 7 步（锚定 → 体检 → 基线 → 归因 → 训练网格 → 样本外 → 真 5 分钟终审）
> 出场默认: 技能 BASE_STOP（止损优先 / 成本-6% / 移动 3.5%·1% / 阶梯 5%·10%各卖50% / 12天）
> 窗口: 训练 2015-2020 / 样本外 2021-2023 / 数据真实 5 分钟终审

## 一句话结论

**这个公式"行"，但只在配对了卖出规矩的时候。**
默认出场（-6% 止损）在真实分钟数据下是亏的（-1.9%/年）；
改良方案（两个信号过滤 + 止损放宽到 -12%）在真实分钟数据下扭亏为盈（+3.3%/年），
且比基线强出统计学显著（P=0.012）。加上之前 2005-2026 全历史验证（用户参数年化 8.4%），
**捉妖是你手里目前唯一能打的公式，继续当主力。**

## 体检

- 无未来函数（重画检测 728 个信号 0 漂移）；
- 信号逻辑：底部区域 + 28 天冷却后首次放量大涨 >9% 的"首板启动"捕捉。

## 冠军方案（明确写法）

- **信号**：GUPIAO_018 原文 ∧ 信号日前 5 天累计涨幅 ≤15%（不追第二脚）∧ 信号日量比 ≤3（不碰爆量）；
- **出场**：止损优先 / 成本止损 **-12%**（默认-6%太紧） / 移动止盈 +3.5%激活·1%回撤 /
  阶梯 +5%卖50%·+10%卖50% / 时间止损 12 天；
- **效果**：真 5 分钟口径下，基线 -1.9% → +1.5% → 冠军 +3.3%，每一步改良都在加分（单调改善）。

## 诚实边界

1. 日线数字（25-35%）按惯例虚高，真 5 分钟下约为 1/10（这次冠军 3.3%），看策略以 5m 为准；
2. 全历史（2005-2026，用户参数）真 5m 年化 8.4%（2万/票）/ 15.1%（10万/票）——
   早年肥近年瘦，2023 年后段收益只有个位数，未来预期按 10% 以内锚定；
3. 高换手（年均数千笔、持仓 4-5 天），实盘先模拟盘验证滑点；
4. 股票池为今日快照，早年有幸存者偏差。
