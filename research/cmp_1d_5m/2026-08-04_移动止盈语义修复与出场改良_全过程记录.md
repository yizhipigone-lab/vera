# 移动止盈语义修复与出场改良 — 全过程记录 (2026-08-04)

> 技能: tdx-strategy-research | 执行人: Kimi Code CLI | 状态: 完成

## 时间线

1. **5M 窗口末日误判退市修复** (上午): core/data_fetcher.py window_mask 终点按时间戳比较,
   win_end 恒为子夜 → 末日全部分钟 bar 被排除, 回测区间末日持仓被误判退市强平 (reason=11)。
   修复为按日期比较 (normalize)。回归测试 tests/test_window_end_clip.py::test_window_mask_includes_full_last_day。
2. **1D/5M 对比实验** (2026-05-01~07-31, 同参数): 1D +6.66% vs 5M -10.57%, 胜率几乎相同。
   逐仓配对 (618 组): 差距全部来自移动止盈 (323 对, 5M 均少 6.3pp, 合计 -18.1万 ≈ 总差 -16.8万)。
3. **机制定位**: ①intraday 1% 回撤线在 5M 噪音带内 (股池日内振幅中位数 6.3%);
   ②stop_first 先到先得在 1D 形成"阶梯值班日 trailing 休息"隐藏语义;
   ③线价成交幽灵化 (93% 成交价高于当日收盘, 中位 +4.44pp)。
4. **调参证伪**: 5M 回撤 3%/5% → -13.7%/-15.3% (比 1% 的 -10.6% 更差, 单调恶化)。
5. **日频确认模式实现**: trailing confirm=intraday(默认,旧行为不变)/low/close;
   日频模式仅当日末根 bar 判定、收盘价成交、阶梯值班日休息。
   改动: trailing.py/loop.py/state.py/prefilter.py/builder.py/engine.py + 9 个新测试用例, 全量测试通过。
6. **语义收敛验证**: 诚实口径下 1D -14.07%/-15.10% vs 5M -14.60%/-15.81% (3个月窗, 差 0.5-0.7pp)。
   688728 案例: 日频模式拿到 +60.8%(Low)/+55.8%(Close), 与 1D 旧语义 +59.2% 行为对齐。
7. **技能流程改良** (§0-§7): 公式审计干净 → 训练窗基线 +103.1% → 归因 → 8 变体网格 →
   4 组合 OOS → 2 组合 5M 终审 → 分层 + bootstrap 显著性 → 双报告。
