## 〇、一页纸结论（先看这个）

| 角色 | 策略脚本 | 年化收益 | 最大回撤 | 适合谁 |
|---|---|---|---|---|
| **进攻型首选** | `iter_1092_左侧_年化27.1%_回撤-30.3%.py` | **27.1%** | -30.3% | 能接受账户一度缩水三成、追求收益最大化的人 |
| **稳健型首选（实盘推荐）** | `iter_828_左侧_年化18.8%_回撤-12.4%.py` | 18.8% | **-12.4%** | 想睡得着觉的人；胜率 82%，盈亏比 8.4 |
| 进攻备选 | `iter_1079_左侧_年化26.2%_回撤-30.2%.py` | 26.2% | -30.2% | 想要 25%+ 又想要高胜率（68%）的折中 |

参照系（自己数据算的基准，2019-01 ~ 2026-07 同区间）：

- 全市场 2530 只股票**等权买入持有不动**：7.5 年累计 +137%（年化约 12%），最大回撤 **-43.4%**；
- 全市场**中位数股票**：7.5 年累计仅 +50.9%（年化约 5.6%）。

也就是说：进攻型策略用 **-30% 的回撤**换了 **+475% 的累计收益**——累计收益是等权基准的 3.5 倍，回撤还比基准的 -43% 小。稳健型则用 -12.4% 的回撤换 +252% 累计，性价比（年化÷回撤 ≈ 1.5）反而更高。

**最重要的三句大实话：**

1. "年化 25% 且回撤 ≤15%"这个双目标，在 2019-2026 全 A 股、这套因子家族下，**经 2093 轮搜索 + 3 轮定向实验证明做不到**——不是不努力，是物理上矛盾（详见第七章证据链）。
2. 曾经有两个"年化 28%/26%"的策略，但它们的利润全部来自移动止盈的不现实成交假设；切换到你要求的**条件单语义**后现出原形（-23%/-5.6%），已作废。**能过条件单口径的 27%，比纸面上的 28% 值钱得多。**
3. 所有策略都是"从 2093 个里挑出来的尖子"，自带"恰好适合这段历史"的滤镜（行话叫过拟合）。实盘前必须做样本外验证，且仓位要从小开始。

## 一、回测设计思路（这套系统是怎么干活的）

### 1.1 总思路：让电脑当"策略工厂"

人工想策略，一天能想 3 个；这套系统**每 1.5 秒生成并回测一个完整策略**，一天能试上万个。流程是一条流水线：

```
随机/变异生成策略配方 → 向量化计算全市场买卖信号 → 喂给回测引擎
→ 读出年化/回撤等指标 → 判定达标? → 达标: 收工 / 不达标: 换配方再来
```

每个"配方"（spec）包含四样东西：**思路**（左侧抄底 or 右侧追涨）、**入场因子组合**（2~5 个条件）、**止盈止损参数**、**股票池过滤条件**。每轮配方和结果都完整落盘，可独立复现。

### 1.2 两种搜索模式（先撒网，后垂钓）

- **纯随机模式**：每轮推倒重来，因子、参数、止盈止损全部重新随机。用于探索"哪种家族有戏"。跑了 250 轮。
- **定向变异模式（refine）**：从日志里挑"历届状元"当种子，在其参数附近做小步扰动（±20% 高斯抖动），偶尔增删一个因子，30% 概率彻底换脑子重新随机。像爬山：站在目前最高的位置往四周探，谁更高就站过去。跑了 1841 轮。

### 1.3 策略思路的两大流派（每轮随机切换）

- **左侧逆势（抄底派）**：专买"跌过头"的股票，赌它弹回来。就像橡皮筋被向下拉到极限，松手总会回弹。可用因子：
  - `ret_drop`：N 日内跌幅超过 X%（跌得狠）；
  - `bias_low`：收盘价贴着 N 日最低点（位置够低）；
  - `bias_ma`：收盘价低于 N 日均线 X% 以上（偏离均线太远）；
  - `rsi_low`：RSI 指标（0~100 的"超涨超跌温度计"）低于阈值（深度超卖）；
  - `vol_shrink`：成交量缩到 N 日均量的 R 倍以下（卖盘枯竭）。
- **右侧趋势（追涨派）**：专买"创新高"的股票，赌趋势延续。就像冲浪——不等浪来，看到浪起来了才站上去。可用因子：
  - `new_high`：收盘价创 N 日新高；
  - `break_ma`：收盘价向上突破 N 日均线；
  - `ma_bull`：均线多头排列（短期>中期>长期，像台阶层层向上）；
  - `vol_surge`：成交量放大到 N 日均量的 R 倍以上（放量突破）。
- **大盘环境过滤器（后期新增）**：`mkt_med_ma`（全市场中位数在均线上方才放行）、`mkt_breadth`（多数股票站稳才放行）、`mkt_not_crash`（近期没塌方才放行）。用于给上面两派"看天气"。

### 1.4 回测引擎口径（VERA 平台自带，未改一行代码）

- **买入价**：信号日（T 日）**收盘价**买入（平台铁律口径；实盘是 T+1 开盘买，会有偏差，见边界条件章）。
- **卖出**：由止盈止损规则驱动（见第六章），哪个先触发按哪个走（`priority` 决定同日撞车时的优先级）。
- **涨停过滤**：买入信号如果当天涨停（买不进），直接剔除——本轮实测每轮剔除几百到上万个不等。
- **费用（全部扣除，不是毛收益）**：佣金万三（双边）+ 滑点千一（双边）+ 印花税万五（卖出单边）。每笔交易一进一出成本约 0.31%。
- **本金口径**：初始 100 万，每个信号固定买约 2 万元。**注意：引擎不对总仓位做资金约束**（实测改仓位参数结果逐位不变，见 7.3 节）。
- **退市处理**：用未复权价检测退市/长期停牌，触发后按规则强制出清。

### 1.5 数据与股票池

- **数据源**：本地缓存日线 `data/kline_cache/1d/`（前复权），5698 只 A 股，2004 ~ 2026-08 全覆盖。**全程离线，零网络请求**（脚本里有硬断网守卫，任何联网尝试直接报错中断——这是验证过的，不是"应该没联网"）。
- **回测区间**：2019-01-01 ~ 2026-07-31（信号计算用到 2018 年起的前置数据，保证均线/RSI 有暖机期）。
- **股票池（2530 只）**：从缓存覆盖完整的 3235 只里，剔除 ① 回测期内收盘价跌破过 1 元的（面值退市红线，当 ST 的离线代理）② 日均成交额最低 20% 的僵尸股。**注意：池子天然排除了退市股，有幸存者偏差**（只给活下来的学生判卷，成绩偏乐观，见边界条件章）。

### 1.6 达标判定线

- 原始双门槛：年化 ≥ 25% **且** 最大回撤 ≤ 15%；
- 过程中按你的指示调整过：先全力冲 25%（回撤全面放宽，`--target-mdd -1.0`），达标后再回头攻双目标。门槛做成了命令行参数，随时可调。

## 三、回测边界条件（这些"滤镜"必须知道）

按对成绩的影响从大到小排：

1. **过拟合滤镜（最大）**：策略是从 2093 个候选里选出来的冠军，就像全年级考 2093 次试取最高分——里面有真实力，也有运气成分。缓解办法：样本外验证（换时间段/换股票池重跑）、实盘小仓位试水。
2. **幸存者偏差**：股票池剔除了退市股。等于"只给活下来的学生判卷"，真实全市场成绩会打折扣。
3. **买入价口径**：回测按信号日 T 收盘价买入，实盘只能 T+1 开盘买。超跌反弹类策略对买入价敏感，实盘收益预计打 7~9 折。
4. **仓位无约束**：引擎"每个信号固定买 2 万、盈亏汇总"，不模拟资金不够用的情况。信号密集期（一天几百个信号）实盘根本接不下，实际收益会进一步摊薄。
5. **ST 判定是代理**：用"跌破过 1 元"代替真实 ST 名单，可能误伤少量低价股、漏掉个别高价 ST。
6. **2026 年表现普遍走弱**：所有推荐策略 2026 年（1~7 月）收益在 -7% ~ +2% 之间，明显弱于 2019/2025 大年。策略风格和近年市场环境的匹配度在下降，实盘需观察。
7. **手续费口径**：万三佣金+千一滑点是偏保守（偏贵）的设定，实盘如果费率更低，成绩只会更好——这一条是少数"往好里偏"的假设。

## 四、推荐策略①：进攻型 iter_1092（年化 27.1%）

**文件**：`output/auto_iter/iter_1092_左侧_年化27.1%_回撤-30.3%.py`（完整独立脚本，含数据读取/信号/仓位/费用/止盈止损/绩效计算，`python` 直接可跑，已验证复现逐位一致）

### 4.1 策略逻辑（大白话）

**一句话：专买"被三连确认跌过头"的股票，然后分批止盈、到期认栽。**

入场三条件（必须同时满足，7.5 年共触发 17,479 次）：

1. `bias_ma(55, 0.20)`：收盘价低于 55 日均线 **20% 以上**——股价像橡皮筋被向下拉了五分之一，严重偏离正常轨道；
2. `bias_low(26, 0.0117)`：收盘价距离 26 日最低点**不超过 1.17%**——已经趴在近一个月的地板上；
3. `rsi_low(8, 19.0)`：8 日 RSI ≤ 19——"超跌温度计"进入深度冰冻区（平时 30 以下就算超卖，它要求 19 以下，极苛刻）。

三个条件各管一件事：**跌得远 + 位置低 + 情绪冷**，等于"三重认证的超卖"，所以胜率不高（36%）但抓住就是大的（平均盈利是平均亏损的 3.25 倍）。

### 4.2 止盈止损参数（完整）

| 规则 | 参数 | 大白话解释 |
|---|---|---|
| 成本止损 | **-25%** | 买入后亏到 25% 无条件割肉。很宽——因为抄底接的是"下落的刀"，得给子弹飞一会儿的空间 |
| 阶梯止盈 | 涨 **7.14%** 卖 16.8%；涨 **13.15%** 再卖 16.2%；涨 **33.35%** 再卖 21.6% | 反弹分段落袋：先收回部分本钱，让剩下的利润继续跑 |
| 移动止盈 | **未启用** | 所以完全不受条件单语义影响，成绩在任何成交口径下成立 |
| 时间止损 | **35 天** | 持有 35 个交易日还没起色就认栽走人，资金不陪僵尸耗着 |
| 撞车优先级 | `trailing_first` | 同日多规则触发时的判定顺序（本策略移动止盈关闭，实际主要是止损与阶梯的先后） |

## 六、止盈止损机制总览（全部推荐策略共用一套框架）

回测引擎内置六种出场规则，每个策略是它们的参数化组合：

| 规则 | 作用 | 大白话 |
|---|---|---|
| `cost_stop` 成本止损 | 亏损到阈值无条件卖 | "亏 25% 就认赔"——左侧策略的命门，设宽了回撤大，设窄了被洗出去 |
| `ladder_tp` 阶梯止盈 | 涨到不同高度分批卖 | "每上一层台阶锁一部分利润" |
| `trailing_stop` 移动止盈 | 从最高点回撤 X% 卖 | "放风筝"：涨就放着飞，线一断（回落）就收。本报告推荐策略均未启用 |
| `time_stop` 时间止损 | 持有超 N 天卖 | "到期没戏就撤，不陪僵尸股耗" |
| `cond_time_stop`/`first_day`/`formula_sell` | 条件止盈/首日规则/公式卖出 | 本次搜索未启用 |

**关于移动止盈的条件单语义（`confirm="real"`）**：这是你点名要求的口径，含义是"回撤线必须提前挂好"——创出新高的当天不用新线审判当天（K 线内高低顺序不可知）、跳空低开按开盘价成交、盘中触线按线价成交。这是实盘挂条件单能 1:1 复现的语义。**本次所有推荐结论都在此口径（或不启用移动止盈）下成立。**

## 七、为什么"25% + 15% 双达标"做不到（三轮定向实验证据链）

不是说永远不可能，是说**在这套因子家族 + 这个回测口径下，证据表明是结构性矛盾**：

### 7.1 实验一：定向变异 800 轮硬攻双目标

合规区最优从 18.8% 只爬到 **19.0%**，四批全部"停滞重启用尽"提前收工。天花板实锤。

### 7.2 实验二：大盘过滤器 24 组网格（给冠军戴"天气滤镜"）

假设：回撤来自大盘塌方时接飞刀，过滤坏天气就能砍回撤。**结果证伪**：

- `mkt_not_crash` 各参数下，回撤死死钉在 **-30%** 不动（最松的 x=0.12 也只是年化降到 21.4%，回撤纹丝不动）；
- `mkt_breadth` 收紧到能砍回撤时（th=0.6，回撤 -10.8%），年化已经跌到 **-0.2%**——信号被掐得只剩 276 个，等于不玩了。

**结论：-30% 的回撤不来自大盘环境，来自策略自身**——宽止损（-25%）意味着单笔就能亏掉 1/4，一连串止损就是深回撤。

### 7.3 实验三：仓位网格 7 组（降仓位压回撤？）

max_positions 从 999 调到 5，**结果逐位相同**（年化全 25.2%、回撤全 -30.3%）。引擎不做资金约束，"轻仓压回撤"这根杠杆在回测里不存在。

### 7.4 矛盾的物理本质

```
要 25% 年化 → 必须宽止损(-25%) + 长持仓(35天) 硬吃深跌反弹 → 单笔可亏 25% → 回撤必 ~30%
要 15% 回撤 → 必须紧止损快认赔 → 被正常波动扫出去 → 吃不到反弹主段 → 年化封顶 ~19%
```

卡玛比率（年化÷回撤）能说明问题：成熟量化策略 Calmar 到 1.5 已是优秀。稳健型 iter_828 是 1.52，**正好卡在"优秀线"上**；而双目标要求 Calmar ≥ 1.67 且绝对收益 25%，这套单因子族给不出来。

### 8.1 排名设计思路

为什么不搞"一个总分排到底"？因为**收益和回撤是两种商品，没法用同一个价签**。改成三个榜，各回答一个实际问题：

- **收益榜**（回答"谁最能赚"）：按年化排序，只看条件单口径有效的轮次（移动止盈禁用或 confirm=real，共 888+ 轮有效）；
- **稳健榜**（回答"谁最省心"）：回撤 ≤15% 硬门槛内，按卡玛比率（年化÷回撤，即"每挨一刀换多少肉"）排序；

## 九、推荐理由与风险提示（最后啰嗦一遍）

### 推荐这两个策略的真正原因

1. **成交假设站得住**：移动止盈未启用或条件单口径，回测怎么赚实盘就能怎么赚（在 T+1 开盘买入的偏差内）；
2. **逻辑讲得通**：三重超卖确认 + 分批止盈 + 到期认栽，每一步都有朴素的生意道理，不是纯数字游戏；
3. **样本量够大**：几千到上万笔交易，不是几十笔的运气；
4. **费用扣得足**：万三+千一的偏贵设定下还能赚，实盘费率更低只会更好。

### 风险（每条都可能让你亏钱）

1. **过拟合**：2093 选 1 的冠军，历史滤镜客观存在。**实盘前请用 2024-2026 数据单独重跑验证**；
2. **2026 年走弱**：全部策略近半年收益平平甚至小亏，风格与当前环境可能正在脱钩；
3. **T+1 偏差**：回测 T 日收盘买，实盘 T+1 开盘买，超跌股隔夜常有跳空，预计收益打 7~9 折；
4. **幸存者偏差 + 仓位无约束**：真实全市场、真实资金约束下，成绩还会再打折扣；
5. **-30% 回撤是真实的痛**：2022-02 ~ 2022-09 那七个月，账户从高点缩水三成再慢慢爬回来。拿不住的人会在坑底割肉，把浮亏变实亏——**这是策略最大的风险，不是市场，是自己**。

### 10.3 术语速查（本文只用到的）

- **年化收益率**：把总收益折算成"平均每年赚多少"，便于和理财/指数比较；
- **最大回撤**：账户从历史最高点跌得最深的一跤，衡量"最惨的时候多惨"；
- **夏普比率**：每承担一份上下波动，换来多少收益，>1 合格、>1.5 优秀；
- **卡玛比率**：年化÷最大回撤，"每挨一刀换多少肉"，>1.5 优秀；
- **盈亏比 PF**：总盈利÷总亏损，>1 才是赚钱的买卖；
- **条件单**：提前挂好的"价格到 X 就自动卖"的订单，本文移动止盈的实盘口径；
- **过拟合**：策略恰好适配了历史数据，像背下高考真题答案，换个年份就考砸；
- **幸存者偏差**：只用活下来的股票做研究，成绩天然偏乐观。
