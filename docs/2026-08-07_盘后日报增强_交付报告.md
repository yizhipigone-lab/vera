## 一、你拿到了什么

打个比方,以前飞书只发"今天赚/亏多少"一个总数;现在每天收盘给你一张**四栏对账单**:

| 栏 | 内容 | 例子 |
|---|---|---|
| **资产** | 总资产 / 市值 / 现金 / 持仓只数 / 浮盈 | 总资产 ¥101 万 · 浮盈 +2,300 |
| **交易摘要** | 买几手卖几手 / 成交额 / 已实现盈亏 + 胜率 | 买 2 · 卖 3 · 成交额 ¥8 万 · 已实现 +1,500 胜率 67% |
| **仓位变动** | 新开 / 清仓 / 加仓 / 减仓(带股号+数量变化) | 清仓 600519(-1000) · 加仓 300750(+200) |
| **卖出明细** | 每笔卖出:盈亏额 / 盈亏百分比 / 卖出原因 | 600519 +1,000 (+10%) · 移动止盈 |

**双端同源**:飞书卡片 和 网页 读的是**同一份账**(`_notify_daily` 算一次,两边各取),不会出现飞书说赚 1000、网页说赚 800 的打架。

**网页怎么看**:分析页日历上,有数据的交易日格子能点;点一下摊开当天对账单,再点一下收起;切月份会自动收起,不会留着旧数据误导你。

## 三、数据怎么流(为什么飞书和网页不打架)

```
每天 15:05 定时器触发
        ↓
_notify_daily 算「今天这一份账」(只算一次)
        ├─→ 飞书卡:_build_daily_card 拼成卡片发出去
        ├─→ 数据库:save_daily_report 存起来
        └─→ 网页:你点哪天,就 /analysis/daily_report 读哪天
```

三个出口同一份源头,所以数字必然一致。**当日盈亏基准仍是盘前那个 `_day_baseline`**(你的铁律:盘前基准不动);昨日的持仓快照只用来算"今天仓位动了啥",不掺进盈亏。

## 四、⚠️ 一个要你拍板的点:可能做重了

**"每笔卖出盈亏落库"这块,深度可能超出你的本意。**

- 你说"全明细",我做到了"每笔卖出都算出精确盈亏百分比、永久存进数据库、随时可查"。
- 但你的本意可能只是**"今天卖了哪几只,大概盈亏,看一眼就行"**。

**如果砍掉这块**:不算成本法盈亏、不建 daily_report 表、不迁移老库,只让飞书/网页列出卖单和金额 → 能省约 40% 工作量和一半测试。**没砍前,上线前的历史成交行那栏会显示"—"(不回填,保持单一口径)。**

要砍现在还来得及,说一声。
