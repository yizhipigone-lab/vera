## 六、警告（尺子已核实到哪，如实说）

1. **回测绝对值不可全信**（项目铁律）：方向系统性乐观；本报告价值在**同口径相对排序**和参数邻域定位，不在绝对年化数字。
2. **回撤被仓位稀释**：单票 2 万 / 300 万 = 0.67% 仓位，回撤天然偏小（黑马 -1.6% 是分散的结果不是策略本身不亏）。若放大单票仓位，回撤近似线性放大，年化也同步放大——Calmar 大体不变，所以**用 Calmar 跨公式比较是稳的**。
3. **引擎版本漂移**：prep 缓存建于引擎 v3.4（2026-07-14），当前引擎 v3.5（2026-07-21 区间精确化，执行窗口与降级网格口径有变）。run_cached 矩阵口径未变、影响有限，但**最终上线的 Top 组合建议用 run() 完整路径复跑核对一次**再信。
4. **达标 0 是正常基线**：年化 >30% 的达标线对无未来函数的干净公式本来就极难；两公式收益天花板 18~19% 即真实水平。
5. 黑马 Top 组合交易数恒为 3403（小于信号数 3803）——部分信号因涨停/停牌/资金约束未成交，属正常过滤。
