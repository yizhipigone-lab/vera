## 三、分析洞察

### 1. 黑马选股1 断崖领先
Calmar 5.1，是第二名的 3 倍。核心优势：**回撤极低（-1.8%）**，移动止盈激活线仅 +2%，几乎是"有赚就锁利润"，配合 81.7% 的高胜率和 3.3 天的短持仓，风险控制做到极致。

### 2. 年化最高 ≠ 排名最高
TKXG/W-105 年化 15.9%（全场最高），但回撤 -9.6% 拖累 Calmar 到 1.7。如果你更看重绝对收益而非回撤控制，TKXG/W-105 是更好的选择。

### 3. 5-8 名完全同数据
突破指标 / 枪挑小梁王 / 次日涨停选股 / 有涨停 四个公式数据完全相同（4308 交易、11.0% 年化、-6.7% 回撤），极可能是同一公式的不同命名或微小变体。建议只保留 1 个。

### 4. 最优参数高度收敛
9/10 公式的最优硬止损都是 -8%，8/10 的最优移动回撤是 0.5%。说明 -8% 硬止损在沪深300 + 止损优先模式下是经过 2592 组合扫描验证的普适最优解。

### 5. 双佛手向上 独特性
唯一使用 -20% 宽松止损 + 4 档阶梯止盈的组合。胜率 79.8%（全场第二高）、盈亏比 2.4（全场最高），但大止损导致回撤偏大。
