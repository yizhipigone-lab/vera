# ADR-0001: 政策匹配三层架构(A/B/C),MVP 先做 A

- **状态**:已接受 (Accepted) — 2026-07-26 用户拍板
- **决策者**:用户(董秘 + 实盘 quant)
- **关联**:[CONTEXT.md](../../CONTEXT.md) 分类体系 / 政策匹配

## 背景

VERA 要结合十五五规划(2026-2030)做 LLM 行业趋势研究层,在选股后做政策匹配研判,提升收益。要求松耦合、只报告不调仓(铁律)、不可回测的因子不进交易链。

**查证事实(2026-07-26,读代码确认)**:

- VERA 选股用的 **881 板块是"行业"**(`881319.SH`=半导体等,池轴实验 128 个行业),非概念。
- 十五五映射里的**前沿产业(低空经济/量子科技/生物制造)是"跨行业概念"**,申万行业分类里没有,881 行业体系落不下。
- 用户映射自带提醒:"政策方向≠短期行情""行业内部分化极大,只看个股转型能力"。
- VERA 轴间实验(2026-07-26):行业轴(动量择行业)对头部 10 公式 **0 胜出**——行业层面信号弱。

三者合力:**行业标签不能做硬过滤,必须能落到个股层面**。

## 决策

政策匹配采用**三层架构**,分阶段建设(**A→B→C**):

| 层 | 干什么 | 技术 | LLM | 可回测 |
| --- | --- | --- | --- | --- |
| **A 行业层** | 行业 → 十五五优先级标签 | 静态 JSON 映射 | 零 | ✅ 历史 |
| **B 概念层** | 关键词命中跨行业概念 | radar_lite | 轻量 | 部分 |
| **C 个股层** | LLM 读主营 → 真假题材 + 业绩兑现 | research_llm | 重 | ❌ 前向评分卡 |

**MVP 只做 A**。A 是地基:免费、零 LLM、可历史回测,先建出来才能往上叠 B/C。

**行业骨架(2026-07-26 补决策)**:A 层以**通达信 881 为唯一行业体系**,不引入申万。理由(用户拍板):通达信永久免费、VERA 已接、无需建"通达信↔申万"映射桥;知识库原按申万组织但只作方向参考,翻译为通达信 881 版即可。原 Q2 的 a/b/c 映射桥方案全部撤销。

**A 层 MVP 范围(2026-07-26 grill 钉定)**:

- 只给**候选池**打标签(不打持仓)——A 层查表零成本,但用户选择先聚焦选股结果,持仓标签等 B/C 收敛时再说。
- **纯展示**(web 加一列);**不做回测验证、不做软排序、不进交易**。
- 档位:第一/二/三优先级 + 规避(代码 `P1/P2/P3/AVOID`);ETF/可转债/不在 128 行业 → "未标"。
- **放弃回测验证**的后果:A 层无数据支撑,价值靠主观辅助 + 给 B/C 喂结构化锚点(用户有意,先看再说;若看完标签觉得有方向,再立项目加回测)。

## 备选方案(被否)

**直接上 C(MVP 就 LLM 个股研判)**——否决:

- 缺 A 的结构化行业锚点,LLM 凭记忆判断"这票什么行业"易幻觉、不可复现。
- A 给 LLM 喂事实("这票是申万半导体,十五五第一优先级"),C 再做语义研判,准确率更高、可追溯。
- A 能独立回测验证"行业优先级有没有预测力";C 不能回测——先验证能验证的。

## 后果

- **正面**:先有免费可回测地基层;B/C 在 A 之上叠加,失败不影响 A;松耦合(每层独立模块)。
- **负面**:A 单独不能解决"真假题材"(要等 C);行业层面信号已被轴间实验证明弱,A 的预测力可能有限——但 A 的价值更在于"给 B/C 喂结构化锚点",不单卖。
- **演进提醒(用户明确要求)**:做完 A 进 B、进 C 时**主动提醒用户**。记录于 memory `policy-research-abc-phasing`。

## 验证标准(待 grill 细化)

- A 层:历史回测"十五五一级行业 vs 规避行业"的收益差,看方向(不强求强度)。
- B/C 层:前向评分卡(实盘积累 3-6 月)。

> 注:2026-07-26 grill Q4 用户**有意放弃 A 层回测验证**(只走展示),故上述"A 层历史回测"暂不执行,留作"看完标签觉得有方向后"的可选立项。
