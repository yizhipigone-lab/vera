## 一、三条源码与合理性评级

### GS0607 捕捉起涨点 (8行, 全段精调 24.4%/-3.4%, 样本外 12-15% 过 10% 门槛)
```
角线:=ATAN((MA(C,5)/REF(MA(C,5),1)-1)*100)*180/π;
角线MA:=MA(角线,5);
ANA/ANB:=PLOYLINE(交叉时连线);   // 仅画线辅助, 未直接参与选股判定
角买点:=CROSS(角线,角线MA) AND ((ANB>REF(ANB,1) AND ANB>ANA AND 角线MA<=0) OR ...);
起涨点:COUNT(CROSS(角线,角线MA), ANA<REF(ANA,5) AND ANB>REF(ANB,5));
```
- 逻辑: 5日均线斜率向上拐头 + 斜率刚从低位(≤0)转正 → 买在起涨点(低吸)
- 无未来函数; PLOYLINE 仅画线不参与计算 → **✅ 逻辑优**

### GS1075 牛角出现 (1行, 粗扫 13.9%)
```
X: (ATAN((MA(C,5)/REF(MA(C,5),1)-1)*100)*180/π) > 60;
```
- 逻辑: 5日均线斜率角度 >60° → 买在已暴涨(追高)
- 极简、无未来函数 → **✅ 简洁自洽, 但追高风险**
- 与 GS0607 同族(ATAN 斜率), 但买点语义相反(高位 vs 低位)

### GS0634 首板启动 (17行, 粗扫 14.9%) — ⚠️ 两类硬伤
```
竞价成交量:=DYNAINFO(15)/DYNAINFO(4);   // 实时竞价数据
强度:=竞价资金/量比*IF(X_4,...);        // X_1=1221030 写死日期(2021年?)
ZZ:=REF(H,BARSLAST(跌8%且量>1.9倍));     // 找上次暴跌
启动:ZZT AND 强度>100 AND HHV(9日涨幅)=今涨幅 AND 占昨量比>0;
```
- **硬伤①**: DYNAINFO(竞价成交/量比) = 盘中实时值。回测是收盘选股口径, TDX 回放给的是当日收盘后快照,
  与实盘盘中触发场景不一致 → 回测数字对实盘乐观, 可信度天然低一档
- **硬伤②**: `X_1:=1221030` 写死日期 + `DATETODAY` 算差 → 疑似原作者时效 hack, 过日后分支失效
- 结论: 粗扫 14.9% 需打折看待, 精调结果仅参考不主推
