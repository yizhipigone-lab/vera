## §0 一句话目标

把 VERA 升级为「**政策研究平台**」：以十五五规划为底层，建持续更新的政策-行业-个股知识图谱（SQLite），对选股+持仓做研判，提供**对话大脑**（Agent SDK）+ **阶段认知笔记**（Obsidian）。**纯研究、绝不联入仓位调度**（业务铁律 1）。

## §1 背景

见[方向讨论稿](./2026-07-27_政策研究平台BC层_方向讨论稿.md)。用户拍板：B 模式（认知体系优先）+ 对话大脑。服务「董秘 + quant」双重身份。

## §6 实施步骤

### P0（1-2 天，零成本零 LLM）— SQLite 存图 + 产业链穿透
**闸门**：持仓票查到上下游 → 进 P1。

### P1（3-5 天，~50 元）— 政策流水线
**闸门**：新政策抽出影响行业 **且抽样人审准确率 ≥80%** → 进 P1.5。

### P1.5（2-3 天，零 LLM）— B 层概念抽取
**闸门**：选股结果看到概念标签列（list 渲染）→ 进 P2。

### P2（2-3 天）— Obsidian vault 双层
**闸门**：graph view 看到关联；用户能在 `notes/` 写理解 → 进 P3。

### P3（7-10 天，v5 工期修正）— 对话大脑 + 阶段认知笔记

> v4 重定义 + v5 沙箱补强。P3 = 对话大脑（主体）+ 月度认知笔记（大脑预设 query）。

**P3.1 对话大脑**（`brain/`，Agent SDK）：
- `ClaudeSDKClient`（多轮有记忆），入口 = VERA web「研究」页签
- **code execution 工具**（不限技能，Claude 自主写 Python/SQL）
- **常用快捷工具**（不限制只加速）：`kg_query`/`trade_query`/`concept_query`/`policy_query`/`counter_evidence`
- **★沙箱必须分两层（C-1 修复，v5）★**：
  - **SDK 层**（管 Claude 主进程工具）：`cwd=vera/` + `disallowed=["Bash","Edit","Write"]` + hooks + plan-approve。**⚠️这只管主进程 tool dispatch，管不到 code execution 容器**
  - **code execution 容器层**（`code_execution_20250825` 独立子进程，**SDK 层防护对它无效**）→ 必须**物理隔离**：
    - **只读挂载**：仅 `kg/` `policy_kb/` `concept_kb/` + 数据文件（`ro` flag）
    - **不挂载**：`trade/` `backtest/` `selection/` `pipeline/`（容器内 `import trade.store` → `ModuleNotFoundError`）
    - **SQLite 只读**：`sqlite3.connect("file:...?mode=ro&immutable=1", uri=True)`，DB 层拒写
    - **断网**：`network_mode=none`（防 `requests.post` 外发持仓）
    - **超时 + 内存上限**：防瞎跑烧钱
- **引用溯源**：每答附「代码+结果」，禁编；判断类给「统计事实 + 多解读 + 反证」，不单一结论
- **★记忆隐私（L-1，v5）★**：`ClaudeSDKClient` 跨轮记忆只存「认知/事实/政策脉络」，**不存持仓数字/策略意图**；prompt 脱敏（中性表述，不发"我在调研 XX 票"）

**P3.2 月度认知笔记**（`notes_gen/monthly.py`）：每月自动跑大脑预设 query → `~/vera_vault/notes/2026-XX.md`（链接客观层）。

**闸门**：
- 用户能问「近三月盈利票在什么政策主线」并得到附代码+结果的回答
- 月度笔记含反证段
- **沙箱逃逸测试全过**（容器内 `import trade.store` 必 ModuleNotFoundError、sqlite 写必失败、requests 必失败）

**合计 ~14-22 工作日**，成本 < 150 元。
