## §4 架构

### 4.1 对话大脑 = Claude Code CLI subprocess + 回答质量防护

```text
用户在研究 TAB 问 "今天买的票哪些不值得？"
  ↓
VERA server.py /api/research/chat (async, asyncio.create_subprocess_exec 不阻塞 worker)
  ↓
brain/claude_cli.py:
  asyncio.create_subprocess_exec(
    "claude", "-p",
    stdin=PIPE,                    # ★M4: prompt 走 stdin (不拼字符串, 防注入)
    input=system_prompt + 对话历史(M2) + 用户问题,
    "--allowedTools", "Read,Grep,Bash",    # 只读 + code execution (C 裸奔: Bash 能写 trade/, 接受)
    "--output-format", "text",
    "--resume", session_id,                # ★M2: 多轮 (Claude Code --resume 持久化 session)
    timeout=120,
  )
  (cc-switch 已配 DeepSeek)
  ↓
Claude Code (DeepSeek) 自主跑 agent loop:
  Read trade/store.db / Read kg/graph.db / Bash 跑 Python / Grep 政策
  → 原始回答
  ↓
brain/ 回答质量三件套 (v2 补):
  ① counter.py: 反证扫描 → 强制 <counter_evidence> 段 (缺失 → 标记低置信)
  ② evidence.py: 引用溯源 → 每个结论附 [代码/结果] (缺失 → 标记低置信)
  ③ memory.py: 多轮历史 → 只存认知/政策脉络 (不存持仓数字/策略意图 L-1)
  ↓
结构化回答 → /api/research/chat 响应 → 研究 TAB 展示
```

**回答质量三件套（v2 补 v5 防护退化）**：
- **反证**（counter.py）：判断类问题必含 `<counter_evidence>` 段（对立事实），正则校验，缺失标记低置信
- **引用**（evidence.py）：每答附「代码+结果」，缺失标记低置信
- **多轮**（memory.py）：`--resume session_id` 持久化，历史不存持仓数字/策略意图（记忆隐私 L-1）

## §5 接缝

### 5.1 Claude CLI subprocess（★v2 诚实修正★）

```python
# brain/claude_cli.py (v2)
import asyncio

async def ask_brain(question: str, session_id: str = None, timeout: int = 120) -> dict:
    """对话大脑: asyncio subprocess 调 claude CLI (cc-switch+DeepSeek). C 裸奔."""
    # M3: 启动前校验 cc-switch provider = DeepSeek
    if not _check_provider_deepseek():
        return {"answer": "cc-switch 未配 DeepSeek, 请切换", "success": False}
    # M4: prompt 走 stdin (不拼字符串, 防注入)
    full_prompt = _build_prompt(question, session_id)  # system + 历史 + 问题
    cmd = ["claude", "-p", "--allowedTools", "Read,Grep,Bash",
           "--output-format", "text"]
    if session_id:
        cmd += ["--resume", session_id]  # M2: 多轮
    try:
        proc = await asyncio.create_subprocess_exec(
            *cmd, stdin=asyncio.subprocess.PIPE, stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE, cwd=str(VERA_ROOT))
        stdout, _ = await asyncio.wait_for(proc.communicate(full_prompt.encode()), timeout=timeout)
        raw = stdout.decode()
        # 回答质量三件套
        answered = counter.ensure_counter_evidence(raw)  # 反证段校验
        answered = evidence.ensure_citation(answered)     # 引用溯源
        return {"answer": answered, "success": True, "session_id": session_id}
    except asyncio.TimeoutExpired:
        return {"answer": "大脑超时", "success": False}
    except Exception as e:
        return {"answer": f"大脑调用失败: {e}", "success": False}
```

**★v2 沙箱诚实声明（C 裸奔）★**：
- `--allowedTools Read,Grep,Bash`：Bash 放行 = **code execution 不限技能**
- **C 裸奔**：Bash 能写 trade/（`sqlite3 trade/store.db` / `python -c "from trade.store import ..."` / `echo > trade/`）。**不加沙箱软闸**（用户拍 C：研究平台+松耦合+铁律8）
- ~~`--disallowedTools Write,Edit`~~：**去掉**（v1 写的"守住 trade/"是错的——disallowed Write/Edit 只管 Claude 自身 tool dispatch，**拦不住 Bash**。C 裸奔下不需要这个虚假防护）
- ~~`--add-dir 圈定`~~：**去掉**（v1 语义错——`--add-dir` 是**扩大**可访问范围，不是限定）
- **风险兜底**：QMT 真相源对账（铁律1，store.db 脏了能发现）+ kill_switch 人工解除（铁律7）+ 研究平台低风险（DeepSeek 按 prompt 分析不主动改 trade/）

@app.post("/api/research/chat")
async def research_chat(body: dict):
    """研究 TAB 对话大脑 (async, 不阻塞 worker)."""
    from brain.claude_cli import ask_brain
    question = body.get("question", "")
