## 第一批实施规格（市场体检表）

- 位置：`brain/data_tools.py` → `market_snapshot()` 内新增"市场体检"小节。

- 内容：4 指数 × 4 窗口（21/63/126/252 交易日）收益率 + 相对 MA250 位置 + 牛熊斜率状态（复用 `research/index_regime.py` 口径：价>MA250 且斜率>0 为牛，价\<MA250 且斜率<0 为熊，其余为震荡）。

- 数据源：TDX 指数日线（`core/data_fetcher.py` 的 `INDEX_CODES` 与 `get_index_data`），随 snapshot 2 小时缓存。

- 交易链路零改动；任何指数取数失败只标"缺"，不影响其余（沿用 data\_tools 既有 fail-soft 风格）。

## 第二批实施规格（sgpjbg 研究热度雷达，已于 2026-09-04 落地）

- 已实现：`brain/sgpjbg_radar.py`（每日抓免费元数据 → `data/sgpjbg_radar.db`；`weekly` 生成独立周报）；
  调度器已注册：每日 17:30 抓取、每日 18:30 检查仅周日生成周报（`output/reports/sgpjbg_研究雷达周报_*.md`）；

- 周报含开头摘要（本周 N 篇/关注相关 M 篇）、行业热度环比、活跃机构 Top10、高热度 Top10、关注概念命中清单；

- 反爬适配：首访 403 发质询 cookie，Session 携带重试即放行（最多 3 次）；

- 红线：不批量下载 PDF；政策/财经/图表数据库不接（与 iFinD/TDX 重叠）。

## 附：IRX DSH 对比研究结论（同日完成）

VERA 大脑架构与 IRX DSH 同构（都是外部 CLI 子进程做深度思考），能力层打平甚至 VERA 更全（golden set 考试、反证校验、快车道）。差距在工程纪律：IRX 有每问留档账本（run\_id/哈希/泄漏扫描）、"留档失败=显性失败"、版本钉死+冒烟。后续可单独立项学这套（P0：brain\_runs 账本、scan\_leak、版本冒烟），不在本决策范围内。
