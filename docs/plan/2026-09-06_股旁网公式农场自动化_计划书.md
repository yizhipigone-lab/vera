### 2.3.2 实测更新(2026-09-06,用户当场试导):文本 .tni 生成 = 否决
按 all_468 样本生成的 [FORMULA] 文本包进公式管理器导入,报 **"无法兼容的公式版本"**,
导入失败且零残留(gs_txt 1525 哈希全不变)。结论修正:
- all_468_formulas.tni 当年"成功导入 397"的证据链不成立或另有其文件——大概率成功的是
  **TDX 自身导出的二进制 .tn6/.tne 包**(at.tn6/通达信2000公式.tne 等本地实物),那种包
  无法程序化自造(二进制专有)。
- **上架可行通道重排**:① [最佳] 图像技能驱动"公式管理器→新建→粘贴源码→确定"(gongshi
  28/417 败因=pywinauto 绝对坐标,改用 image-based 动态匹配+状态等待重做,TDXDLDATA 已证明
  菜单流可行);② [低科技兜底] 半自动:farm 产出 N 条待录文本,人在公式管理器手工 新建+粘贴
  (每日几条可接受,去重由 farm 保证);③ 文本 .tni/.txt 导入通道 —— 未证实,不做承诺。
- pack_tni 模块保留(v0 已验证与样本格式自洽、可作留痕/文档),但标注为**非上架通道**。

(全网佐证:该报错=公式包版本不匹配/非官方包的经典提示;参考 55188/叩富/搜狗问问相关问答,
通用教程类: zhibiao365.com/149698、cjm99.com/jc/148074。)

### 2.3.1 否决前的复核记录(保留追溯;结论以 2.3.2 为准)

用户质疑"自写官方公式包行不行"。当时复核推断"行",依据:gongshi 里
`all_468_formulas.tni`(385KB)是**程序拼出来的明文文本**,不是 TDX 导出的:

- 编码 **GBK**(非 UTF-8),468 个 `[FORMULA]` 段,每段:
  `[FORMULA]\r\nName=GSxxxx\r\nType=XG|ZHU\r\nDesc=<gupang 来源URL>\r\nParam=\r\n\r\n<公式源码>`,
  段间以空行分隔(实测两段间尾字符为 `\r\n\r\n`)。
- `Name=GS0000..GS0467`(纯 ASCII 编号),`Type=XG`(选股,323 条)/`ZHU`(主图,145 条),
  `Desc` 全部是股旁网原文 URL —— TDX 自己的导出绝不会带"来源网址"字段,
  证明该文件是外部按此格式生成的。
- 它确实被 TDX 公式管理器成功导入:今天 `E:\NEW_TDX\T0001\export\gs_txt\gs_2_GS*.txt`
  397 条(UpdateDate:20260828)就是残留物证。
- ⚠️ gongshi 目录只剩 `_batch_import.py`(GUI 死路)与 `_batch_retry.py` 两个 py,
  **拼 .tni 的脚本没留档** —— 这就是"感觉生成不了"的来源:能复用的不是脚本,
  是那个成功过的实物文件本身。
- 风险与对策:格式规范无公开文档(全网只有通用导入教程,见计划书底部引注),细节
  (GBK vs 其他编码、Type 码 XG/ZHU 与 TDX 内部类型 15/5 的映射、Name 长度/字符限制)
  以实物样本字节级复刻 + **单条 round-trip 导入测试**为 gate,通过后才批量(测试公式
  验完即删)。此为 v0 必过闸,不猜。

### 2.4 去重基线(用户要求"只做没做过的")
- **已做集合** = ① gongshi 468 篇 md 的 `来源 URL`(文章 id ~699xx-70xxx,2026-03~06) ∪
  ② gs_txt 里 GS 批次 397(≈①子集) ∪ ③ 全量 1525 gs_txt 的 Source Code **内容哈希库**
  (防"同源码换标题再发") ∪ ④ farm 自身 intake 历史。
- 判重双键:**文章 URL/id** + **归一化源码哈希**(去空白/大小写后 sha256)。
- 两键任一命中 → 跳过,记"重复"。

## 6. 纪律(不可违反,含 gongshi 血泪)

1. **GUI 逐条录入公式 = 永久禁用**(gongshi 实测 28/417)。上架只走官方导入;
   包装格式改动必须先做 round-trip 测试。
2. 网页源码先 **HTML 实体还原**(`&NBSP;` 曾致"未知字符串"导入失败)。
3. 体检双闸:静态黑名单 + 上架后 repaint/future_func 定量复核。
4. 调参与验证分窗;快出场必须真 5m 终审(1d 虚高 4~5 倍)。
5. 动 TDX 前留快照(gs_bak 日备份已在做,导入前手动再留一份);只增不改;失败可回滚
   (删自己导入的 GS 记录)。
6. 回测口径:T 收盘买入;universe 显式;绝对收益不可全信,相对排序可信。
7. 入选 ≠ 上实盘,人工把关。
