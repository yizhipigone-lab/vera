## 二、三条红线（本次一个都不碰）

1. **业务铁律 1**：事件只进报告，绝不联仓位调度。新源只扩大"发现面"。
2. **事实溯源铁律（2026-09-19）**：候选分两级——`fact_level="primary"`（美联储 RSS、财联社电报等，可指原文）/
   `"secondary"`（华尔街见闻转述，普通重大及以上档必须复核到一手原文才可入库）。
3. **数据流铁律**：事件仍只经 `record_event` 落台账 `events.jsonl`，快照仍只在仪表盘刷新时烤入；
   「扫描收尾必刷新」约定不变。

## 三、模块设计（深模块，接口零膨胀）

新增 **`core/market_event_sources.py`（取数层）**，与既有「纯数学层 `market_position.py` / IO 层 `market_position_runner.py`」
同款分层：sources 只做"联网取数 + 归一化"，对事件分级/衰减一无所知；scan 只做"判定辅助 + 落库"。

```
core/market_event_sources.py   公开接口 3 个（深模块：小接口厚实现）
├── fetch_all_candidates(days, today)   遍历 _SOURCES 注册表，逐源 try/except，归一化输出
├── fetch_treasury_2y_rows()            美财政部 CSV → [(date, rate), ...] 旧→新，失败 None
└── fetch_akshare_2y_rows()             akshare 美债2年 → 同构序列（fed_rate 兜底源）
    私有: _http_get / _fetch_akshare_cls|ths|sina(自 scan 迁入) / _fetch_fed_rss / _fetch_wscn_lives
          _norm_* / _parse_dt / _SOURCES 注册表(加新源=加一行)

core/market_event_scan.py      公开接口保持 7 个，一个不增（铁律 8 上限内有富余）
├── fetch_candidates        改薄：sources.fetch_all_candidates → 时间窗过滤 → MACRO_KEYWORDS 粗筛 → 排序
├── fetch_fed_rate_proxy    财政部主源 → akshare 兜底 → 双源同日偏差 >5bp 写 cross_check 告警
└── RUBRIC                  加「溯源终点清单」一节
```

- **候选 schema** 增加 `fact_level`（primary/secondary）与 `hint`（如"美联储一手·货币政策类"）两个字段，
  供扫描 Agent 执行溯源铁律；旧字段（title/content/date/source/url）不变，`record_event` 等旧函数零改动。
- **美联储 RSS 两个坑（已被 fixture 锁死）**：①响应带 UTF-8 BOM（`EF BB BF`），必须 `utf-8-sig` 解码；
  ②pubDate 是 GMT，FOMC 声明 18:00 GMT = **北京时间次日凌晨 2 点**，事件日期按北京时间折算
  （9月16日 18:00 GMT → 事件日 9月17日）。
- **财政部 CSV**：年度文件、**最新行在最上**、"2 Yr" 列；基准取倒数第 21 个有效行（对齐 akshare `iloc[-21]`
  的"约一个月前"语义）；与 akshare 同取时 |差|>0.05%（5bp）在返回 dict 加 `cross_check` 告警串。

## 四、调度挂载（P1）

`scheduler/__main__.py` 的 `_job_market_dashboard_fill`（08:30）开头插入：

```python
# 先刷新美联储利率预期常驻事件(美债2年一手源), 再补齐快照 —— fail-soft, 失败绝不阻塞补齐
try:
    from core import market_event_scan as ms
    r = ms.update_fed_rate_event()
    _logger.info("fed_rate 跟踪器: %s", ...)
except Exception as e:
    _logger.warning("fed_rate 跟踪器刷新失败(不阻塞仪表盘): %s", e)
```

- 时点依据：美财政部日度收益率美东傍晚发布 ≈ 北京时间清晨，08:30 必能取到 T-1 值；
- **不加新 job、不加进程**（复用既有 fill job）；16:30 close 不挂（此刻美国当天还没收盘，取的是同一行）；
- **上线硬约束**：改完必须重启 scheduler 进程才生效；`market_event_scan`/`market_event_sources`
  不被 server/trade_main 引用（已 grep 实证），**core 层改动零重启**。
