# 2026-08-20 回测"次日开盘价买入"模式(entry_price_mode=open_t1) 计划书

> **背景(大白话)**: QUANTQQ 是尾盘选股策略——收盘前选出股票、按当天收盘价买入。
> 现在的问题是:如果信号股当天**涨停**了,尾盘挂单根本买不进去(涨停拒单),
> 回测引擎里的 `_filter_limit_up` 会把这些信号直接扔掉。用户想要一个新选项:
> **信号日当天买不到就算了,改成第二天开盘价买入**;只有第二天是"一字涨停"
> (开盘=最高=最低=收盘,全天钉死在涨停板上,谁也买不进去)才放弃这笔。
>
> 打个比方: 现在的回测是"今天打烊前买,卖完了就走人";新模式是
> "今天卖完了,明天开门我第一个来买;除非明天门口挂着'整天缺货'的牌子(一字板),
> 那我认栽"。

## 1. 总体设计

### 1.1 方案选型

| 方案 | 做法 | 评价 |
|---|---|---|
| **A. 引擎层矩阵变换(推荐)** | 在 engine 把"信号日 T 的入场信号"平移到"T+1 首个可交易 bar",买入价矩阵换成开盘价; 主循环几乎不动 | 改动面最小, 卖出/权益/止损逻辑零触碰, 快照 parity 天然不破 |
| B. 改 BacktestLoop 主循环 | 循环内识别"延迟信号", 每 bar 检查前一天信号 | 动核心循环, parity 风险大, 违反"新功能优先独立新文件"约定 |

**选 A**。核心洞察: 回测循环里 `EntryEngine.run_bar` 的买入价就一行
`bp = price_np[i, ci]`(backtest/loop/entry.py:72)。只要在外层把
**①信号矩阵平移一天 + ②给 EntryEngine 传一张"买入价矩阵"(=开盘价矩阵)**,
循环本身不需要知道发生了什么。

### 1.2 数据流

```
信号日 T 收盘出信号 (entries)
        │
        ▼  open_t1 模式时(新模块 backtest/entry_next_open.py)
┌─────────────────────────────────────────────┐
│ 1. 每个信号 (T日, 股票) → T+1 日             │
│ 2. T+1 是一字涨停(OHLC 四价合一且达涨停价)?   │
│    → 是: 丢弃 + 计数                          │
│ 3. 找 T+1 日首个可交易且开盘有价 bar          │
│    → 全天没有: 丢弃 + 计数                    │
│ 4. T+1 超出数据窗口: 丢弃 + 计数              │
│ 5. 输出: 平移后的 entries + 统计             │
└─────────────────────────────────────────────┘
        │  entries_shifted + buy_price_np(=open 矩阵)
        ▼
_resolve_stop_and_build_loop → build_backtest_loop(buy_price_np=...)
        → EntryEngine(params, buy_price_np) → run_bar 里 bp = buy_price_np[i, ci]
```

### 1.3 一字板判定规则(严格按用户口径)

T+1 日级别判定:
- `day_open == day_high == day_low == day_close`(四价合一 = 全天只有一个价)
- **且** `day_close >= 前收盘 × (1 + 涨停幅度) × 0.997`(确认是一字**涨停**, 不是一字跌停/平盘——一字跌停随便买, 不拒)
- 涨停幅度复用 `engine._limit_ratio_vector`(core/limit_ratio.py 唯一真相源: 主板 10% / 创业科创 20% / 北交所 30% / ST 5%)

分钟级(5m/1m)周期: 日 OHLC 由当日 bar 聚合(open=首 bar open, high/low=当日极值, close=末 bar close), 与 `_filter_limit_up` 的分钟级处理口径一致。

### 1.4 与现有机制的交互

| 机制 | open_t1 模式下的行为 |
|---|---|
| `_filter_limit_up`(T 日涨停过滤) | **跳过**(由 T+1 一字板判定替代) |
| degrade_5m 的 1d 涨停拒单 | `apply_5m_degradation` 传 `limit_ratio_vec=None` 关闭(T 日不成交, 拒单无意义) |
| 卖出/止损/移动止盈 | 零改动, 仍按收盘价路径 |
| 换股 reason=1 | 旧仓以 T+1 开盘价卖(见 D4) |
| 权益曲线/期末未平仓 | 零改动 |
| 持仓天数 max_hold_days | 从 T+1 入场 bar 起算(自然结果, 无需处理) |
| 快照 parity | 默认 close_t 模式**字节级不变**, `tests/test_snapshot_parity.py` 必须原样通过 |

```python
# backtest/entry_next_open.py
"""open_t1 入场口径: 信号日 T → T+1 开盘价买入 (2026-08-20 计划书 Task 1).

规则 (用户口径):
- T 日收盘出的信号, 移到 T+1 日首个可交易 bar, 以该 bar 开盘价买入
- T+1 一字涨停 (日 OHLC 四价合一 且 >= 前收*(1+涨停幅度)*0.997) → 拒买
  (一字跌停/平盘不拒 — 跌停随便买; 涨停价开盘但盘中有成交也不拒)
- 信号日已是数据最后交易日 → 丢弃 (遵守 v3.5: 执行窗口=请求区间, 不外延取数)
- T+1 全天无可交易 bar (停牌) → 丢弃

纯函数, 不进 BacktestLoop; loop 侧只需要 buy_price_np=open 矩阵 (Task 2)。
"""
from __future__ import annotations

from dataclasses import dataclass

import numpy as np
import pandas as pd


@dataclass(frozen=True)
class T1ShiftResult:
    entries: pd.DataFrame          # 平移后的入场信号 (与原 entries 同 shape)
    n_signals: int                 # 原始信号数
    n_shifted: int                 # 成功平移数
    n_oneline_limit_up: int        # T+1 一字涨停拒买数
    n_no_t1_bar: int               # 无 T+1 数据丢弃数 (信号日=最后交易日)
    n_no_tradable_bar: int         # T+1 全天不可交易丢弃数


def shift_entries_to_next_open(
    entries: pd.DataFrame,
    open_df: pd.DataFrame,
    high_df: pd.DataFrame,
    low_df: pd.DataFrame,
    close_df: pd.DataFrame,
    limit_ratio_vec: np.ndarray,
    tradable_np: np.ndarray | None = None,
) -> T1ShiftResult:
    idx = entries.index
    cols = entries.columns
    n = len(idx)
    day_id = idx.normalize()

    # ── 日级聚合 (分钟级 → 日 OHLC; 1d 恒等) ──
    day_close = close_df.groupby(day_id).last()
    day_open = open_df.groupby(day_id).first()
    day_high = high_df.groupby(day_id).max()
    day_low = low_df.groupby(day_id).min()
    uniq_days = day_close.index.sort_values()
    day_pos = {d: k for k, d in enumerate(uniq_days)}

    # ── T+1 一字涨停判定: 四价合一 且 达涨停价 ──
    prev_close = day_close.shift(1)
    ratio_s = pd.Series(np.asarray(limit_ratio_vec, dtype=np.float64), index=cols)
    one_line = ((day_open == day_high) & (day_high == day_low)
                & (day_low == day_close))
    at_limit_up = day_close >= prev_close * (1.0 + ratio_s) * 0.997
    yiziban = (one_line & at_limit_up).fillna(False)

    # ── 每 bar → 所属交易日; 每日首 bar 位置 ──
    day_arr = day_id.values
    bar_day_pos = np.array([day_pos[d] for d in day_id])
    day_bars = [np.nonzero(bar_day_pos == k)[0] for k in range(len(uniq_days))]

    open_v = open_df.values
    new_vals = np.zeros(entries.values.shape, dtype=bool)
    n_signals = n_shifted = n_yz = n_no_t1 = n_no_trad = 0

    for bar_i, ci in np.argwhere(entries.values):
        n_signals += 1
        k = bar_day_pos[bar_i]
        if k + 1 >= len(uniq_days):
            n_no_t1 += 1
            continue
        k1 = k + 1
        if bool(yiziban.iloc[k1, ci]):
            n_yz += 1
            continue
        target = None
        for b in day_bars[k1]:
            if (tradable_np is not None and ci < tradable_np.shape[1]
                    and not tradable_np[b, ci]):
                continue
            op = open_v[b, ci]
            if np.isnan(op) or op <= 0.0:
                continue
            target = b
            break
        if target is None:
            n_no_trad += 1
            continue
        new_vals[target, ci] = True
        n_shifted += 1

    return T1ShiftResult(
        entries=pd.DataFrame(new_vals, index=idx, columns=cols),
        n_signals=n_signals, n_shifted=n_shifted,
        n_oneline_limit_up=n_yz, n_no_t1_bar=n_no_t1,
        n_no_tradable_bar=n_no_trad,
    )
```
