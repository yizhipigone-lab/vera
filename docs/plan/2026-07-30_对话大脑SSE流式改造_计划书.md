## 1. 问题（不变）

### 1.1 盲等问题
研究页"对话大脑"发问后，前端只显示"大脑思考中… 已耗时 X 秒"（纯前端计数器）。后端 `_run_once` 用 `proc.communicate()` 一次性读完——期间无反馈。用户无法判断大脑是否在工作/在干什么/还要等多久。

### 1.2 复杂任务超时
`timeout=300, max_turns=20`。简报生成（搜索行情+政策+公告+研报+资金流+社媒）20 轮不够，300s 不够。实际案例：用户提交"今日热点追踪简报"超时。

## 2. 方案（不变 + M-4 修正）

### 2.1 核心思路
claude CLI 逐行输出 stdout → SSE 实时推前端 → 替换盲等计时器。

## 3. 详细设计

### 3.1 `brain/claude_cli.py`

**签名变更（加 `on_line`）：**

```python
# on_line: async callable（返 None），不是 async generator
# ask_brain 内部 `await on_line(line)` 调用它
on_line: Optional[Callable[[str], Awaitable[None]]] = None
```

**★v2 H-2: `_run_once` 流式路径（杀树明确）★**

```python
async def _run_once(command, prompt_bytes, on_line=None):
    proc = await asyncio.create_subprocess_exec(
        *command, stdin=PIPE, stdout=PIPE, stderr=PIPE)
    # ★v2 M-2: stdin 传 prompt（复用原文，流式不改启动方式）
    proc.stdin.write(prompt_bytes)
    await proc.stdin.drain()
    proc.stdin.close()

    if on_line is None:
        # 原路径：communicate 一次性读（一字不改）
        stdout, stderr = await proc.communicate()
        return stdout.decode('utf-8', 'replace')

    # ★v2 新路径：流式读 stdout + 并发累积 stderr + 超时杀树 + cancel 响应
    deadline = asyncio.get_event_loop().time() + timeout
    stderr_chunks = []

    async def _read_stderr():
        while True:
            chunk = await proc.stderr.read(4096)
            if not chunk: break
            stderr_chunks.append(chunk)

    async def _read_stdout_lines():
        while True:
            # ★v2 H-2: wait_for 包裹 readline，超时杀树
            remaining = deadline - asyncio.get_event_loop().time()
            if remaining <= 0:
                proc.kill()
                raise asyncio.TimeoutError()
            line = await asyncio.wait_for(proc.stdout.readline(), timeout=remaining)
            if not line: break
            await on_line(line.decode('utf-8', 'replace').rstrip())

    try:
        # ★v2 M-3: 并发读 stdout（逐行→on_line）+ stderr（累积）
        await asyncio.gather(_read_stdout_lines(), _read_stderr())
        await proc.wait()
    except asyncio.CancelledError:
        # ★v2 H-3: 客户端断开 → cancel 传播 → 杀 proc（防泄漏）
        proc.kill()
        raise

    stdout_data = b''
    # stdout 已逐行消费，这里拿不到完整——改用 proc.stdout.read() 残余
    # 实际上 _read_stdout_lines 已逐行调 on_line，最终答案由 ask_brain 外层拼
    return stdout_data.decode('utf-8', 'replace')  # 流式模式返空（答案在 on_line 回调里）
```

**注意**：流式模式下，claude CLI 的 stdout 逐行通过 on_line 推给前端。最终答案也通过 on_line 推（最后一行/多行）。`_run_once` 返回值在流式模式下可能不完整（stdout 已逐行消费）。**ask_brain 外层要调整**：流式模式不靠 `_run_once` 返回值拼答案，而是 on_line 回调已推完全部内容，最终 done 事件用 on_line 推完后的 `proc.returncode` 判断成功/失败。

**简化**：ask_brain 流式路径：
```python
if on_line:
    # 流式：on_line 推全部 stdout 行 + 最终 done
    await _run_once(command, prompt_bytes, on_line=on_line)
    return {"answer": "(见流式输出)", "success": proc.returncode == 0}
else:
    # 同步：communicate 一次性读
    raw = await _run_once(command, prompt_bytes)
    ...后处理（archive/counter/evidence）...
```

### 3.2 `server.py` — ★v2 H-1 asyncio.Queue 桥接★

```python
@app.post("/api/research/chat/stream")
async def research_chat_stream(body: dict):
    """对话大脑 SSE — asyncio.Queue 桥接 on_line 回调与 yield。"""
    from fastapi.responses import StreamingResponse
    from brain.claude_cli import ask_brain

    question = (body.get("question") or "").strip()
    if not question:
        return JSONResponse({"answer": "请输入问题", "success": False}, status_code=400)

    async def generate():
        queue: asyncio.Queue = asyncio.Queue()
        SENTINEL = None  # 结束标记

        async def on_line(line: str):
            await queue.put(line)  # ★async callable 返 None（不是 generator）★

        # ask_brain 跑在 task 里，on_line 回调 put 到 queue
        task = asyncio.create_task(ask_brain(
            question, timeout=480, max_turns=40,  # ★v2 M-1: SSE 480s（流式简报任务长）
            channel=_brain_channel(body.get("conv") or ""),
            on_line=on_line,
        ))

        try:
            while True:
                line = await queue.get()
                if line is SENTINEL: break
                yield f"data: {json.dumps({'type':'line','text':line}, ensure_ascii=False)}\n\n"
        except asyncio.CancelledError:
            # ★v2 H-3: 客户端断开 → cancel task（防 claude 进程泄漏）
            task.cancel()
            raise
        finally:
            if not task.done():
                task.cancel()
                try: await task
                except asyncio.CancelledError: pass

        # ask_brain 完成 → done 事件
        try:
            result = await task
        except Exception as e:
            logger.warning(f"SSE ask_brain 异常: {e}", exc_info=True)
            result = {"answer": f"大脑调用失败: {e}", "success": False}
        yield f"data: {json.dumps({**result, 'type':'done'}, ensure_ascii=False)}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```

**★v2 H-1 修正说明**：v1 把 `on_line` 写成 async generator（yield），ask_brain `await on_line()` 会 TypeError。v2 改 asyncio.Queue 桥接——`on_line` 是 async callable（put 到 queue），`generate()` 从 queue get + yield。**类型匹配**。

**★v2 M-1**：SSE 端点 timeout=480/max_turns=40（流式简报任务长），旧端点 300/20（同步短问答）。
