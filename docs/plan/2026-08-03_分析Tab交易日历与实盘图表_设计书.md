## 1. 动机与范围

### 1.1 为什么做

VERA 当前有 5 个 Tab：回测 / 体检 / 交易 / 研究 / 记录。交易 Tab 只做实时监控（持仓/委托/急停），缺少对**实盘历史业绩**的回顾分析能力。回测 Tab 有完善的图表体系但只服务于回测结果。

本次在交易 Tab 右侧新增**"分析"Tab**，专做实盘业绩分析：
- **交易日历**（参照 MQ 日历平台）：月历网格，每日盈亏一目了然
- **实盘图表**（复用回测图表能力）：权益曲线 + 基准对比 + 月度热力图 + 盈亏分布

### 1.2 范围

| 包含 | 不包含 |
|------|--------|
| 交易日历（月视图，TDX 数据源） | 多市场日历（仅深市/沪市合并） |
| 实盘权益曲线（5 基准叠加） | 回测 vs 实盘对比 |
| 月度收益热力图（Year × Month，每格数值） | 周度/季度热力图 |
| 盈亏分布 + 卖出原因饼图 | 实时推送（切换 Tab 时刷新） |
| 成交明细表（筛选+分页） | 导出/分享 |
| KPI 卡片（10 个指标） | 自定义 KPI |
| 空状态（无交易 / 加载中 / 错误） | 离线模式 |

### 1.3 与回测图表的关系

| 维度 | 回测图表（已有） | 实盘分析（新增） |
|------|-----------------|-----------------|
| 数据源 | `output/last_result.json` | `trade/store.py` + 新增 `daily_asset` 表 |
| 权益曲线 | 回测模拟 equity | QMT 日终总资产快照序列（新增落盘机制） |
| 基准对比 | 上证/沪深300/创业板/科创50/中证A500 | 同左，新增独立指数拉取端点 |
| 月度热力图 | 回测区间 | 实盘起至今 |
| 成交明细 | 回测信号→模拟成交 | QMT 真实成交（含来源/原因） |
| 日历 | 无 | 月历 + 每日盈亏标注 |

### 2.3 关键设计决策：逐日净值来源

**问题**：现有 `position_snapshot` 只存最近一次快照（`DELETE FROM` + 全量重插），无逐日历史。

**决策**：新增 `daily_asset` 表。每天 EOD（收盘后）由 trade 消费者线程写入一条当日总资产快照。首次部署时，对历史日期从 `trades` 表回放构造（已实现盈亏逐笔累加，未平仓按最后已知市价 mark-to-market）。

```sql
CREATE TABLE IF NOT EXISTS daily_asset (
    date        TEXT PRIMARY KEY,   -- YYYY-MM-DD
    total_asset REAL NOT NULL,      -- QMT 总资产（fetch_asset 返回值）
    available   REAL NOT NULL,      -- 可用资金
    market_value REAL NOT NULL,     -- 持仓市值
    ts          REAL NOT NULL       -- 写入时间戳
);
```

**历史回填**：对于 `daily_asset` 表不存在的历史日期，用以下算法近似：
1. 从最早成交日开始，初始资产 = 首日 QMT 总资产（或 trade config 里的 `initial_capital`）。
2. 逐日累计：`当日资产 = 前日资产 + 当日已实现盈亏 + 持仓市值变动`。
3. 持仓市值变动 = `Σ(当日收盘价 - 前日收盘价) × 持仓量`，从 TDX 日线拉取。
4. 非交易日：沿用前一日值（**carry-forward，不插值**）。

**QMT 对账**：`daily_asset` 表的当日行必须与 `GET /api/trade/asset` 的 `totalAsset` 一致（± 1% 容差）。偏差 >1% 时前端 KPI 卡片旁显示 ⚠ 标记 + tooltip "净值推算与 QMT 资产偏差 X%"。这是 CLAUDE.md 铁律 1（QMT 是唯一真相源）在设计里的落地。

### 2.4 关键设计决策：初始资金

`initial_capital`（累计收益的分母）来源优先级：
1. trade config 新增字段 `initial_capital`（手动设置）
2. 若未设置，取 `daily_asset` 表最早一条的 `total_asset`
3. 若 daily_asset 也为空（全新实盘），分析页显示空状态引导

### 2.5 新增 API 端点

#### `GET /api/calendar?year=2026&month=8`（server.py:8080）

```json
{
  "year": 2026, "month": 8,
  "trading_calendar": {
    "2026-08-03": {"is_trading": true, "weekday": 1},
    "2026-08-04": {"is_trading": true, "weekday": 2},
    "2026-08-08": {"is_trading": false, "weekday": 6}
  }
}
```

数据来源：`DataFetcher.get_trading_dates("SH", start, end)`（复用既有封装，自带 `_ensure_ready()` 初始化 + 空值兜底）。按月查询，返回当月全部自然日。

降级：TDX 离线时读 `data/trading_calendar.json` 静态文件，前端显示 "日历数据来源: 本地缓存"。

#### `GET /api/benchmark/history?indices=shanghai,hs300,chuangyeban,kechuang50,zhongzhengA500&start=2026-01-01&end=2026-08-03`（server.py:8080）

```json
{
  "shanghai": [{"date": "2026-01-02", "close": 3245.67}],
  "hs300": [{"date": "2026-01-02", "close": 3890.12}]
}
```

数据来源：`DataFetcher` 的 `INDEX_CODES`（`core/data_fetcher.py:65-72`）。**开工前需验证 `000510.SH`（中证A500）在 TDX 真实可拉。** 如不可用，降级为 4 基准。

#### `GET /api/trade/analysis/summary`（trade/api.py:8081）

```json
{
  "start_date": "2026-01-05",
  "end_date": "2026-08-03",
  "initial_capital": 1000000,
  "current_asset": 1353300,
  "cumulative_return": 0.3533,
  "annualized_return": 1.6125,
  "max_drawdown": -0.0842,
  "max_dd_recovery_days": 18,
  "max_dd_recovered": true,
  "sharpe_ratio": 4.98,
  "sortino_ratio": 3.21,
  "calmar_ratio": 19.16,
  "win_rate": 0.699,
  "profit_loss_ratio": 1.63,
  "total_trades": 615,
  "profit_factor": 1.85
}
```

#### `GET /api/trade/analysis/equity`（trade/api.py:8081）

```json
{
  "equity": [
    {"date": "2026-01-05", "equity": 1000000, "drawdown": 0},
    {"date": "2026-01-06", "equity": 1008500, "drawdown": 0}
  ]
}
```

数据来源：`daily_asset` 表（EOD 快照）+ trades 回放（历史回填期）。`drawdown = equity / 历史最高 equity - 1`。

#### `GET /api/trade/analysis/daily_pnl?year=&month=`（trade/api.py:8081）

```json
{
  "2026-08-03": {"pnl_rate": 0.0235, "pnl_amount": 23500, "buy_count": 2, "sell_count": 1},
  "2026-08-04": {"pnl_rate": -0.008, "pnl_amount": -8000, "buy_count": 0, "sell_count": 2}
}
```

**盈亏算法（精确定义）**：

```
当日盈亏金额 = 当日总资产 - 前一日总资产（均为 daily_asset.total_asset）
当日盈亏率   = 当日盈亏金额 / 前一日总资产
```

`buy_count` / `sell_count` 从 `trades` 表按 `date(ts)` 聚合（买=方向买入 / 卖=方向卖出）。

**盘中 vs 盘后**：今日格子数据来自 QMT 实时资产查询（`/api/trade/asset`），非 EOD 快照。前端在今日格子上标记"实时"（半透明背景 + 文字标注"盘中"），当日 15:00 后 EOD 快照写入后消除。

### 3.4 日历格子详细规格

每个格子（~100×80px，响应式缩放）：

```
┌──────────────┐
│ 15         │ ← 日期数字 (12px JetBrains Mono, 左上 padding 4px)
│        WEB  │ ← 终端标签 (10px, 右上, system/manual/空不显示)
│             │
│   +2.35%    │ ← 盈亏率 (16px JetBrains Mono 700, 绝对居中)
│  +¥8,520    │ ← 盈亏金额 (11px JetBrains Mono 500, 居中)
│             │
│ 买2  卖1    │ ← 当日成交笔数 (10px, 底部居中)
└──────────────┘
```

**颜色优先级（从高到低）**：
1. `box-shadow: 0 0 0 2px var(--accent)` + 微金背景 → **今天**
2. `box-shadow: 0 0 0 2px var(--accent2)` → **选中**（点击后）
3. `radial-gradient(circle at 50% 50%, color-mix(in srgb, var(--up) 22%, transparent), color-mix(in srgb, var(--up) 6%, var(--surface)))` → **盈利日**
4. `radial-gradient(circle at 50% 50%, color-mix(in srgb, var(--down) 18%, transparent), color-mix(in srgb, var(--down) 5%, var(--surface)))` → **亏损日**
5. `var(--surface)` → **休市/周末/非当月**

**交互三态**：

| 状态 | 视觉效果 |
|------|---------|
| 默认 | 按上述颜色规则 |
| hover | `transform: scale(1.05)` + `box-shadow: var(--shadow-md)` + 亮度+5%，transition 150ms |
| focus | `outline: 2px solid var(--accent)` + `outline-offset: -2px`（键盘 Tab 导航） |
| selected | `box-shadow: 0 0 0 2px var(--accent2)` |
| today+selected | 金边框优先，内阴影加蓝 |

**可访问性**：每个格子 `role="button" tabindex="0" aria-label="8月3日 盈利2.35% 买入2笔卖出1笔"`。

### 3.5 权益曲线基准对比

从 `web/js/charts.js:454-523` 的内联代码**抽取为导出函数** `renderEquityCurve(domId, data, colors)`：

- 接受参数：DOM 容器 ID、`{equity[], benchmarks{}}`、colors 对象
- 5 条基准：上证 / 沪深300 / 创业板指 / 科创50 / 中证A500
- 颜色：`--bm-1` ~ `--bm-5`（复用）
- 图例：ECharts legend，点击切换显示/隐藏
- 基准线：`type: 'dashed'`，1px；策略线：实线 2.5px
- 基准归一化：首个共同交易日 = 0%
- dataZoom：inside + slider
- toolbox：saveAsImage + restore

**charts.js 修改量**：仅抽取导出，不改现有行为。`renderAllCharts` 内部改为调用 `renderEquityCurve`。回测页和分析页均通过同一函数渲染。

### 3.6 月度收益热力图规格

参照 `output/reports/_20260525_011430.html` 的热力图：

- Y 轴：年份（最新年在上）
- X 轴：1月~12月
- 每格：数字 + "%"（如 `+5.2%`）
- 颜色梯度：`--up` 和 `--down` 按透明度分 5 档
  - +10%以上: `var(--up)` 不透明
  - +5~10%: 80%
  - 0~5%: 40%
  - -5~0%: `var(--down)` 40%
  - -10~-5%: 80%
  - -10%以下: 不透明
  - 无数据月: `var(--surface)` + "—"
- Hover tooltip: `2026年8月: +2.3% (盈利15笔 / 亏损8笔 / 共23笔交易)`

### 3.7 空状态设计

## 4. 交互规格

- ECharts `resize()` 在侧栏折叠/展开时触发

- 切换 Tab 时全量重拉 summary + equity + daily_pnl
- 日历数据按需拉取（翻月时）

## 7. 风险与注意事项

| 风险 | 缓解 |
|------|------|
| daily_asset 表从零开始时无历史 | trades 回放 + TDX 日线 mark-to-market 构造历史净值（非交易日 carry-forward） |
| TDX 交易日历离线 | 降级 `data/trading_calendar.json`（预置 2025-2027），前端标注来源 |
| 中证A500 指数 TDX 不可用 | 降级为 4 基准，开工前 P1.6 先验证 |
| 重建净值与 QMT 真值漂移 | 对账机制：偏差 >1% 时前端 ⚠ 标记。daily_asset 表以 QMT 值为准 |
| 手续费未计入导致收益高估 | 摘要文字标注"未含手续费"（与 trade/ 模块 P2 补算保持口径一致） |
| 盘中刷新 daily_pnl 数据不完整 | 今日格子标记"盘中"半透明样式，15:00 后消除 |
| 手工卖出 trades.reason 为空串 | 饼图增加"人工卖出"分类：`source='manual'` 或 `reason=''` 的卖出归入此类 |
