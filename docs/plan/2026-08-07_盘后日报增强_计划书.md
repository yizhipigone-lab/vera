## 一、背景与目标

### 用户诉求
现盘后日报卡只 5 个用户可见数字 (总资产/市值/现金/当日盈亏/持仓只数; 现 payload 7 字段含 ts/day_pnl_pct 2 个派生/元数据)。用户要: 当日交易情况、仓位变动、盈利情况、资产变动 —— 对账单级别。

### 用户拍板的四点 (2026-08-07 讨论)
1. **时机**: 保持 15:05 一次 (搭现成 EOD 车, 接受清算尾差)
2. **深度**: 全明细 (资产 + 交易 + 仓位变动 + 卖出盈亏明细)
3. **回看**: 飞书 + web 分析 Tab 都要
4. **基准**: **盘前基准不动** (`_day_baseline` trade_main.py:430-434) —— 盘前资产 = 昨夜清算完的真实日终, 比 15:05 存的昨日 EOD 更准 (15:05 当日清算没完, 含尾差)

### 目标
- 飞书日报卡升级为多 section 全明细
- web 分析 Tab 可按日回看历史日报 (与飞书同源 payload)
- 数据全部来自已有 store/book, 不新增采集

## 五、数据契约 (v2: 补单位/边界/排序/口径)

### payload 字段 (notify_daily 入参, 同时存 daily_report)
```json
{
  "total_asset": 1023456.78, "cash": 343456.78, "market_value": 680000.00,
  "day_pnl": 3456.78,
  "day_pnl_pct": 0.34,           // 百分数: 0.34 = 0.34% (代码 ×100, trade_main.py:804)
  "position_count": 12,
  "floating_pnl": 8456.00,       // = market_value − Σ(volume×avg_cost); 纯浮盈, 不含税费, 不含已实现盈亏, 与 realized_pnl 分开
  "buy_count": 3, "sell_count": 5, "turnover": 123000.00,
  "realized_pnl": 2100.00,       // Σ 当日卖出 pnl_amount (book 成本法, 见 §四-9)
  "win_rate": 0.60,              // 盈笔/卖笔; sell_count=0 → null (卡片该指标省略)
  "position_changes": {          // 仅当有 prev_snapshot 才出现; 按 (今日 curr vs 昨日 prev) 净 volume diff 分类
    "new":     [{"code":"600519","name":"贵州茅台","delta":100}],
    "closed":  [{"code":"300750","name":"宁德时代","delta":-200}],
    "added":   [{"code":"002594","name":"比亚迪","delta":200}],
    "reduced": [{"code":"601012","name":"隆基绿能","delta":-300}]
  },                             // delta = curr_volume − prev_volume (净变化量, 非逐笔)
  "sell_details": [              // 按 ts 升序 (与成交记录页一致); 超 8 笔留前 8, 折叠部分单列 sell_details_folded
    {"code":"300750","name":"宁德时代","reason":"硬止损","pnl_pct":-2.10,"pnl_amount":-630.0}
  ],
  "sell_details_folded": {"count": 3, "sum_pnl_amount": -450.0},  // 仅超 8 笔时出现
  "ts": 1234567890.0
}
```
- **所有 `*_pct` 字段均为百分数** (如 -2.10 = -2.10%, 0.34 = 0.34%); 前端勿误当小数
- **`pnl_amount`/`realized_pnl` 口径** = book.apply_trade 前快照成本 (§四-9)
- **`daily_report.date` 格式** = `YYYY-MM-DD` (与 daily_asset 同, 前端直传不转换)

## 七、风险与缓解

| 风险 | 缓解 |
|---|---|
| 15:05 清算未完 → 卖出明细缺最后几笔 | `_on_eod` 开头先 `reconciler.sync_reports()` 补齐当日成交 (§四-1, 直接调绕过时段守卫); 实在缺的次日对账修正 (用户已知尾差) |
| 昨仓快照缺失 (昨日程序没开 / query_positions 空) → 仓位变动无基准 | `_diff_positions` 对 prev_snapshot=None 整组省略 + 不报错; 资产/交易部分照发 |
| 卖出笔数多卡片长 | sell_details >8 笔折叠 (ts 升序留前 8); config daily_report_level=summary 完全省略明细 |
