## 1. 策略完整规格

### 1.1 信号（买入）

| 项 | 值 | 来源 |
|---|---|---|
| 因子 | MA 金叉 10/30（短均线上穿长均线） | `auto_strategy_optimizer.py:146-150` |
| 精确逻辑 | 今日 `MA10 > MA30` **且** 昨日 `MA10 <= MA30` | 同上 |
| 触发动作 | 信号日 T **收盘价**买入（铁律：非 T+1 开盘） | CLAUDE.md 业务铁律2 |

```python
# auto_strategy_optimizer.py:146-150
def f_ma_cross(close, ..., fast=5, slow=20, **_):
    maf = close.rolling(fast).mean()   # MA10
    mas = close.rolling(slow).mean()   # MA30
    return (maf > mas) & (maf.shift(1) <= mas.shift(1))   # 金叉
```

## 2. 119 组合证据链：为什么 18.88% 不可达

用户约束"2006 起 + 年化>18.88%"。四池 × 6 因子 × 多出场 + 多因子叠加 = **119 组合穷证**，0 个达标。

### 2.1 四池天花板（单因子 × 多出场）

| 池 | 天花板年化 | 数据残缺² | 评价 |
|---|---|---|---|
| 沪深300（300 超大盘） | **14.43%** | truncated 1328 | 最诚实，但收益最低 |
| **中证500（500 中盘）** | **17.68%** | truncated 2292 | **综合最优**（收益第二、回撤最浅 -25%、夏普最高 1.33） |
| 中证1000（1000 小盘） | 17.84% | truncated 5051 | 虚高，回撤 -43.58% 灾难 |
| 中证A500（500） | 17.96% | — | 虚高，段2 腰斩 -52.85% |

² `truncated` = `kline_cache.py` 缺早期数据直接跳过的股票数（越多越不可信）。

**结论**：四池天花板 14-18%，无一个达 18.88%。中证500 综合最优，定为本档案池。

### 2.2 因子横评（中证500，6 因子）

| 因子 | 20 年表现 |
|---|---|
| **MA金叉10/30** | **唯一有效**（17.68%）—— 跨四池的稳健赢家 |
| MA金叉5/20 | 7.5 年窗口赢，20 年衰减 |
| 突破/动量/放量 | 全部崩盘 -99%（信号爆炸 → 过度交易 → 成本吃光利润） |
| 低波动突破 | 胜率高但年化低（7.83%） |

**结论**：MA金叉10/30 是唯一能扛 20 年的因子，定为本档案信号。

### 2.3 多因子叠加证伪（35 组合，0 达标）

| 叠加方向 | 组合数 | 达标 | 结果 |
|---|---|---|---|
| 大盘 MA250 择时（熊市空仓） | 7 | 0 | 年化 17.68%→**14.94%**（降！躲刀也躲肉） |
| 个股质量过滤（趋势/量能/动量） | 14 | 0 | 过滤越多越差（MA金叉已是完整信号，叠加=冗余确认砍利润） |

**根因（铁律）**：MA金叉本身已是完整的趋势过滤器，它在熊市天然少开仓、开仓后跌破均线快速止损。再叠任何确认层，必然砍掉最赚钱的早期金叉。**多因子叠加对本策略是负贡献**。

### 2.4 小盘高 beta 陷阱（实测打脸"小盘赚更多"）

中证1000 年化 17.84% ≈ 中证500 17.68%（仅多 0.16%），但回撤 **-43.58% vs -25.51%**（多亏 18 个百分点），夏普 1.04 vs 1.33。**小盘涨得猛跌得也猛，跌的吃掉涨的，风险翻倍收益不增。**

### 3.3 策略性格（数据洞察）

> **这套策略的钱，是在熊市和震荡市赚的，不是在牛市赚的。**

- **牛市跑输大盘**：2006(-51.9%)、2009(-24%)、2014(-38.9%)、2025(-11.5%) —— 大盘疯涨时 MA金叉滞后 + 中盘弹性弱，垫底。
- **熊市大幅跑赢**：2008(**+68.9%**，大盘-65% 它+3%)、2011(+26.1%)、2013(+33.7%)、2015(+22.4%)、2018(+9.6%)、2022(+16.7%)。

**比方**：像个"不冲顶但特别抗摔"的选手。alpha 全在"别人亏钱时它少亏甚至小赚"。这性格直接解释了 §2.3 为什么大盘择时是负贡献——择时砍熊市仓位 = 砍掉策略最值钱的能力。

### 4.2 结合择时能否优化？——诚实三层

1. **简单大盘择时（熊市空仓）**：**已实测证伪**（§2.3，0/7 达标，17.68%→14.94%）。根因：策略 alpha 在熊市，砍熊 = 砍肉。

## 5. 通达信(TDX)公式复刻 ★

### 5.1 可复刻边界（诚实声明）

| 层 | 复刻度 | 说明 |
|---|---|---|
| **买入信号** | **1:1 等价** | `CROSS(MA(C,10),MA(C,30))` 与 Python `(MA10>MA30)&(MA10.shift(1)<=MA30.shift(1))` 定义完全一致 |
| 硬止损 -8% | 近似 | TDX `LOW<=止损价` 触发；Python 按止损价成交，TDX 信号不指定成交价（跳空低开时成交价有差） |
| 时间止损 20天 | 1:1 等价 | `BARSLAST(BUY)>=20` |
| **移动止盈** | **近似，非1:1** | `confirm="real"` 三条语义（创新高bar不触发/跳空按开盘价/按线价成交）需有状态跟踪，TDX 无状态公式**无法精确复刻** |
| 仓位管理(5仓/单票10万/冷却20天) | **无法复刻** | 这是组合层管理，TDX 公式只管单股信号，必须在交易系统/人工层做 |

> **核心提示**：TDX 公式只能复刻**单股信号层**。组合管理 + 移动止盈条件单语义必须靠外部系统。直接拿 TDX 公式跑回测，数字会和 Python 引擎差 3-5%（移动止盈是高频触发项）。

### 5.2 买入信号公式（1:1 等价，可作选股公式）

```
{=== 中证500 MA金叉10/30 — 买入信号 (与Python引擎1:1等价) ===}
{用法: 通达信选股公式, 选股时限定板块为中证500成分股, 尾盘14:50后运行}
MA10 := MA(CLOSE, 10);
MA30 := MA(CLOSE, 30);
金叉10_30 : CROSS(MA10, MA30);
{选股输出: 金叉10_30 = 1 的股票, 信号日收盘价买入 }
```

**等价证明**：
- Python `f_ma_cross`：`(MA10 > MA30) & (MA10.shift(1) <= MA30.shift(1))` = 今日 MA10>MA30 且昨日 MA10≤MA30。
- TDX `CROSS(A,B)` 官方定义：A 上穿 B = 今日 A>B 且昨日 A≤B。
- **两者逐字等价**。

### 5.3 出场预警公式（近似复刻）

```
{=== 中证500 MA金叉10/30 — 出场预警 (近似复刻, 非字节级parity) ===}
{用法: 通达信条件预警公式, 加载到持仓股上, 触发即人工/系统卖出}

{---- 买入信号与买入价 ----}
MA10 := MA(CLOSE, 10);
MA30 := MA(CLOSE, 30);
BUY := CROSS(MA10, MA30);
BN := BARSLAST(BUY);                       {距上次买入天数}
BPRICE := VALUEWHEN(BUY, CLOSE);           {买入价=信号日收盘}

{---- 出场1: 硬止损 -8% (Low触发) ----}
止损价 := BPRICE * 0.92;
硬止损 : (LOW <= 止损价) AND (BN > 0);

{---- 出场2: 时间止损 20交易日 (Close执行) ----}
时间止损 : (BN >= 20) AND (BN > 0);

{---- 出场3: 移动止盈 (激活4%/回撤1%, 近似) ----}
{买入后最高价}
最高自买 := HHV(HIGH, BN + 1);
{激活: 最高价曾达买入价104%}
已激活 := 最高自买 >= BPRICE * 1.04;
{回撤线 = 买入后最高价 × 0.99}
回撤线 := 最高自买 * 0.99;
{触发: 已激活 且 收盘跌破回撤线}
{⚠️ 近似: 未复刻 confirm=real 的"创新高bar不触发""跳空按开盘价""按线价成交"}
移动止盈 : 已激活 AND (CLOSE <= 回撤线) AND (BN > 0);

{---- 卖出总信号 (止损优先) ----}
卖出 : 硬止损 OR 时间止损 OR 移动止盈;
```

### 5.4 在通达信里的使用流程

1. **池限定**：通达信建"中证500"自定义板块（或用 `.CSI500` 指数成分），所有选股/预警限定此板块。
2. **买入**：14:50 后用 §5.2 选股公式选出当日金叉票，**按收盘价挂单买入**（实盘注意深市 14:57 后收盘竞价规则：买挂涨停价、卖挂跌停价，单一价格撮合）。
3. **仓位**：人工/交易系统层控制——最多持 5 只，单票 1-10 万，清仓后 20 天冷却。
4. **卖出**：持仓股加载 §5.3 预警公式，触发任一出场信号即卖。

### 5.5 TDX 复刻 vs Python 引擎的已知差异（必须知道）

| 差异点 | 影响 |
|---|---|
| 移动止盈条件单语义未复刻 | 高频触发项，预计影响年化 3-5%（TDX 版收益会偏离 Python 17.68%） |
| 成交价（止损按线价 vs TDX 按收盘） | 个别跳空交易日成交价不同 |
| 仓位/冷却/资金管理 | TDX 不管，全靠人工纪律，纪律不严=实盘偏离 |
| 印花税率（0.05% 固定 vs 实际 2023.8 前 0.1%） | TDX 不计成本，需自己在预期里扣 |

**建议**：TDX 公式用于**信号发现 + 人工预警**（它的强项），不要用它跑精确回测。精确回测以 Python 引擎为准。若要 TDX 回测数字可信，需另建 parity 测试校准 §5.3 的移动止盈近似。

## 6. 实盘可落地性诚实评估

### 6.1 四条硬警示

1. **段1虚高**：17.68% 被 2006-2012（29.94%）拉高，剔除后真实 12-15%。

## 附录 A：为什么是"候选"不是"上线"
