## 二、规则改了什么（大白话版）

| 维度 | 旧规则（MA20 三态） | 新规则（动量） |
|---|---|---|
| 选腿 | MA20 方向 + 250 日回撤 | 两只风险腿各算 4 周动量，**谁涨跟谁**，动量最高且 >0 的满仓 |
| 躲跌 | MA20 向下 → 满仓黄金 | 两只腿动量都 ≤0 → 满仓避险篮子（**默认单黄金 = 空仓买黄金**） |
| 止损 | 无（靠三态切换） | **日频移动止损**：持仓期最高价回撤超 15%（可配）→ 当日切避险 |
| 调仓节奏 | 每日算信号+调仓 | **周频信号 + 次日执行**：每周最后一个交易日算信号存起来，次日尾盘执行；中间每天只做止损检查 |
| 腿数 | 单主腿（创业板50） | 双风险腿（创业板50 + 纳指，第二腿可配可关） |

「满仓」始终 = ETF 池的 100% = `etf_ratio × 总资产`，不是整个账户。

## 三、回测依据（数字带参照）

研究脚本 `research/etf_momentum_*.py` 系列实证（**口径注意**：回测用 399673 指数代理创业板50，因 159949 上市前无数据；指数 vs ETF 跟踪价差预期 ±1~2%/年，只标注不消除）：

- **黄金版（空仓买黄金）**：全窗口 **+4415.4%**，最大回撤 **-31.7%**，Calmar **1.21**，夏普 **1.36**，换腿约 180 次 / 11.4 年。
- **两腿现金版**：+2221%，回撤 -34.4%（不如黄金避险，故默认避险=黄金）。
- **逐年亮点**：2016 +3.7%、2022 +7.1%——两个股灾年靠黄金避险转正，这是「空仓买黄金」的核心价值。
- 换腿成本口径：**双边合计 0.1%**（ETF 免印花税，仅佣金，卖旧+买新两笔共扣）。

### 4.1 `trade/rotation.py` 核心改动

1. **`compute_momentum_signal(closes_by_leg, momentum_window)`**：纯函数，逐腿算
   `m = 末收盘 / N 日前收盘 − 1`，取最高且 >0 的腿；全 ≤0 → `target=None`（避险）；
   数据不足 → `target=None + insufficient=True`（fail-safe 切避险）。
2. **`momentum_target_values(...)`**：目标腿 100% 池 / 避险篮子按 `hedge_ratio` 拆分
   （`hedge_etf2` 空 = 单黄金，`hedge_ratio` 仅其非空时生效）。
3. **`_is_signal_day(d, signal_day)`**：信号日 = 每周最后一个交易日 ≤ 锚定 weekday，
   节假日休市自动前移（接 `scheduler/trading_calendar.next_trading_day`）。
4. **`_execute`**：输入从「三态 state」改「目标代码 target」；换档判断从派生状态改
   「当前持仓 ≠ 目标」；**日频移动止损**（持仓期最高收盘 H，回撤超阈值切避险 + 清
   `pending_target`）；保留 can_use 回填（159949 事件修复）。
5. **`_worker` + `on_signals`**：周频信号日只存 `pending_target` 不执行；非信号日
   执行持久化 target（含止损检查）；冷启动从 `rotation_state` 恢复 `entry_high`/`pending_target`。

### 4.2 配置变更

删除 4 个 MA20 专用字段：`signal_index` / `ma_window` / `high_window` / `drawdown_threshold`。
新增 4 个字段（含默认值）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `risk_etf2` | `513100.SH` | 第二风险腿（纳指），空=单腿退化 |
| `momentum_window` | `20` | 动量窗口（交易日，20=4周） |
| `trailing_stop_pct` | `0.15` | 日频移动止损回撤阈值 |
| `signal_day` | `friday` | 周频信号锚定日 |

## 七、上线注意事项

1. **线上 `config/trade.yaml` 是 gitignore 的**（含账号敏感信息，不进 git），字段迁移已
   直接改在盘上；`execute_time` 保持线上原有的 `14:55` 未动（迁移只动 4 个字段，不动时点）。
2. **旧 MA20 函数保留但标 deprecated**（`compute_signal`/`STATE_RATIOS`/`target_values`/
   `_derive_state`）：因 `research/*.py` 里 9 个历史回测脚本仍 import 它们，一次性清理属
   独立任务，本轮未做。
3. **已知取舍（计划书 §八 自审已标注）**：黄金避险腿自身下跌不设止损；V 型反弹踏空是
   日频止损固有代价；回测/实盘口径差不消除。
4. **信号日优先级**：日频移动止损优先于周频信号执行；止损触发会清空 `pending_target`，
   后续守避险直到下个信号日重算。
