**同类遗漏复查**:对全库再 grep 一遍 `_build_trade_summary|_enrich_sell_quotes|_diff_positions|_entry_and_closed|_calc_drawdowns|_rows_to_dicts|_name_of(|_diff_dicts(|_deep_merge(|_trading_days(`,确认除已修的 trade_main.py:335 外无其他残留引用。`notifier.py` 的 `self._name_of` 是 FeishuNotifier 自身方法(非 api 函数)、`monitor.py` 的 `self._hold_days` 是注入属性、`brain/alert_rules.py` 与 `utils/config_loader.py` 的 `_deep_merge` 是各自独立实现,均非本次下沉对象,不误伤。
