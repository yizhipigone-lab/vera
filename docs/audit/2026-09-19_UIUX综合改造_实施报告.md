## 二、新 TAB 修复清单（本次核心）

1. **运算符优先级 bug（P0）**：`historySummaryText` 抽出为纯函数，三档方向词（转暖/转冷/持平）。修复前 Node 实测输出「变化 +0.80）；近7日均值 5.50。」（前缀整句被吞）；修复后完整显示。回归锁：tests/js/test_market_dashboard.js 19 例。
2. **写死颜色全灭（P0）**：40 余行 CSS 从 JS 字符串注入迁回 index.html 内联样式层，类名不变、全走令牌；JS 只加 class。迁移后自动获得双主题换血与 prefers-reduced-motion 降级。
3. **倒计时生命周期（P0）**：新增 `marketPageLeave`（vera-ui.js 同步补调用）+ visibilitychange 按绝对时间重算；到点自动刷新时历史页签在场会一并补刷历史图。
4. **图表主题化**：echartsInit 复用 charts.js 共享注册表；配色全部来自 getColors()（accent 琥珀金主线 + text2/border 坐标轴 + 主题化 tooltip）；主题切换经 MutationObserver 盯 data-theme 自动重上色（**与计划的偏差**：原计划包装 `toggleTheme._onToggle` 回调链，但 vera-ui.js 模块顶层会直接覆盖该回调，包装会丢失，故改 MutationObserver，无顺序依赖）。
5. **温度分语义修正**：高低不再用涨跌红绿 —— 热 ≥6.5=--warn-text、温 4.5~6.5=--text、冷 <4.5=--info-text；红绿只留给"较上日/较30日"的方向变化；事件修正分 0 落灰不落绿。
6. **其余**：手动刷新按钮带已耗时秒数；错误口径走 describeFetchError（连不上 8080 / 服务端报错 / 超时三分开）；子页签 tablist/tab/aria-selected/tabpanel 语义；mdHint aria-live=polite；明细页文案改为实话（原文承诺的"口径说明悬浮"实际未实现）。
