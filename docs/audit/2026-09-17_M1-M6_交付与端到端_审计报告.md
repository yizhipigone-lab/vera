**不通过（HEAD 这批交付物不能就这样交给小白用；4 条必须先修，其中 1 条会让数据列整列是空的）。**

一句话总结：**大盘位置这一套（体温表、照镜子、影子规则、指标体检）文字质量是项目史上最好的**
——白话、打比方、主动讲局限，小白基本读得懂。**但有两个硬问题**：

1. **HEAD 上 `daily.jsonl` 的第 9 列 `regime_20`（20% 法则牛熊口径）在 5501 条记录里

   **文本列 `regime_20` 交给了数值转换函数**，`float("bull")` 抛错被吞掉 → 静默变 `None`。

   而那个文件根本不存在**（目录都没建）；它的"留意清单"里有一行是把程序原始 JSON
   直接倒给用户；它把持仓成本印成 `2.16647264589018` 这样的 16 位小数。

### F-00【HIGH】HEAD 上 `regime_20` 列 5501 条记录**全空**（文本列被数值转换吃掉）

- **结论**：HEAD 的 `daily.jsonl` 里，第 9 列 `regime_20`（20% 法则牛熊口径）**没有任何一个非空值**。
  我只读解析自己的两次采集产物：**16503 / 16503 个指数位全是 `None`**（5501 行 × 3 个指数）。
  也就是说「牛熊区间」这一节的第二条口径**没有落进数据**。
- **证据**：
  - 生产方式：`tools/market_position_collect.py --md …`（HEAD 代码，采集时刻约 03:02–03:05）。
  - 我解析 `scratch/audit_daily_before.jsonl`（第 1 次采集产物）与 `scratch/audit_daily_run2.jsonl`（第 2 次）：
    两者 `regime_20` 的取值分布都是 `{None: 16503}`。

    `item[col] = _f(r[col]) if col != "regime" else (None if … else str(r[col]))`
