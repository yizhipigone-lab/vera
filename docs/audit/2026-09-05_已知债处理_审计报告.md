## 三、发现的契约问题（已修正）

**前端 client 无 body 调用会 422（埋雷）**：
- 后端 `research_api.py:186-198` `reset/stop` 声明 **`body: dict`（必填）**；
- 首版 client `resetResearchChat = body => post(..., body)` / `stopResearchChat = body => ...` 参数化后**无 body 调用时 post 不发 body** → FastAPI 422；
- 未来 brain_chat（classic）迁移时若漏传 body 即踩雷。
- **修正**：client 默认参数 `body = {}`（`post` 对 `{}` 会带 JSON `{}`），防 422；注释提示调用方仍需带 `conv`/`{run_id}` 语义。审计已复跑 node --check 绿。
