# 板块诊断 — 成文模板

数据来源：`python -m brain.data_tools market_snapshot`（指数 + 涨停池行业分布）、
`zt_pool`（涨停池明细）、`kg/graph.db`（产业链穿透）、
`policy_kb/tongdaxin_priority.json`（十五五政策档位 P1/P2/P3/AVOID），
新闻面用 `stock_news` / search_web 补充。

规则与个股诊断相同：不编数字、区分【事实】/【解读】/【待验证】、
不下买卖指令、遵守 A股特色纪律、读者是入门者要配大白话。

## 输出结构（严格按此七段）

1. **一句话结论**
2. **板块表现总结**：目标板块近期表现、相对大盘强弱、
   涨停池里该板块的家数（资金温度计的粗口径，注意说明这是粗口径）。
3. **板块轮动分析**：当前市场热点识别、该板块所处轮动阶段
   （启动 / 发酵 / 退潮）、与政策档位的关系（P1/P2 有政策主线加持，
   P3/AVOID 需说明为什么仍在/不在关注范围）。
4. **同业对比**（若用户给了具体个股）：个股在行业中的地位
   （龙头 / 第二梯队 / 跟随）、估值相对水平（无数据标【待验证】）、
   与行业龙头的差距。
5. **结构化评估**（打标必须给出依据）：
   - 板块热度：🔥热门 / ⚡一般 / ❄️冷门
   - 资金方向：💰流入 / 💸流出 / ⚖️平衡（依据：涨停家数变化、成交额、
     南向资金、新闻里的资金流报道；北向已停披露不可用）
   - 个股位置：👑龙头 / 🥈第二梯队 / 🥉跟随（给了具体票才评）
6. **风险提示**：该板块特有的风险（政策变化、产能过剩、地缘传导等）。
7. **`<counter_evidence>` 段**：与主结论相反的事实或风险（铁律，不可省）。
