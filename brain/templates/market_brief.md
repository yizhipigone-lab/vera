# 大盘/盘面 — 成文模板

数据来源：`python -m brain.data_tools market_snapshot`
（A股/港股/美股指数 + 南向资金 + 涨停池，akshare 直取，2 小时缓存）。

规则与个股诊断相同：不编数字、严格区分【事实】/【解读】/【待验证】、
不下买卖指令（VERA 是纯研究助理）、遵守 A股特色纪律
（北向实时流向已停披露，别编北向数字）、读者是量化入门者要配大白话、表格优先。

## 输出结构（严格按此六段）

1. **一句话结论**：今天市场整体是强是弱、方向一句话说清，附风险等级。
2. **市场概况**：
   - A股主要指数（上证/深成/创业板/科创50/沪深300/上证50）今日涨跌幅；
   - 港股恒生系、美股三大指数（隔夜收盘）表现；
   - 涨停池家数（市场情绪的粗口径，说明这是粗口径）。
3. **技术面与趋势**：指数所处位置（用快照里的数字）、关键支撑/压力、
   近期趋势方向（上涨 / 下跌 / 震荡）。
4. **市场宽度与资金**：
   - 涨停池的行业分布（哪些板块在冒头、资金往哪走）；
   - 南向资金最近 3 日流向（北向已停披露，不可编）。
5. **风险提示**：当前盘面最主要的几个风险（政策变化 / 地缘 / 情绪过热 / 缩量等），
   每条给依据。
6. **`<counter_evidence>` 段**：与主结论相反的事实或风险（铁律，不可省）。
